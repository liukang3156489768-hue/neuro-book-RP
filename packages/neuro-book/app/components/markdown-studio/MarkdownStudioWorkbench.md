# 文稿工作台

通过 controller、文稿 content、tabs/activePath/node、编辑器类型与视图、主题与编辑偏好组合工具栏、欢迎页、富文本/源码/只读编辑区、批注。不直接读取作品 store 或调用 API。切换文件时通过显式 controller 清理上一个文件的批注视图。编辑、保存、标签操作、创建文档与打开引用通过已有事件和回调交回宿主。

根容器随可用空间收缩，不强制640px最低宽度；390px 窗口保留编辑区，宽内容由具体编辑器处理。compact 仍传递给需要紧凑展示的子视图。无文件时显示真实欢迎操作，不填充示例章节。面板隐藏与项目生命周期由页面负责。
