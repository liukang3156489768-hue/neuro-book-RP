# 伏笔库面板

大纲工作台“伏笔库”页的宿主。左侧是伏笔列表，右侧直接编辑选中的伏笔：没有查看态和编辑态之分，改动自动保存为草稿。面板负责伏笔的全部写入：自动保存、新建、确认设计和删除。伏笔在章节大纲正文中的标记由大纲库负责，这里只展示已采用章节大纲里的正式来源。

## 布局

顶部是“新建伏笔”和说明，其下依次是错误条、“未保存修改”切换提示和删除影响面板。主体左右两栏：左栏伏笔列表，每行带状态标签，标记顺序异常时带警告图标；右栏自上而下是状态行（状态、已过格数、保存状态、确认设计、删除）、需要确认时的提示条、伏笔表单（名称；表面线索与背后关联；埋设建议三项；回收建议三项；补充说明富文本）和正式来源列表。最下方在有解析异常时列出各章节的标记诊断。`390×844` 下两栏改为上下排列，表单内并排字段都改为单列。

## 交互

- 自动保存：停止输入约 1 秒、或焦点离开表单时保存。埋设或回收建议只填了一部分时显示“暂未保存”和原因，填齐或清空后继续保存。
- 已确认设计的伏笔：有改动时出现提示条，点“保存并回到草稿”后才保存，也可以“撤销修改”。
- 版本冲突：伏笔在别处被改时，本地没有修改就直接载入新内容；有修改则提示冲突，可“载入最新内容”丢弃本地修改。
- 切换伏笔前先保存；保存不了时出现提示条，可以留在当前伏笔，或放弃修改再切换。
- 新建：点击即以草稿创建“新伏笔”，选中并全选名称。
- 确认设计、删除前先保存；本地有未保存修改时这两个按钮暂不可用。删除先展示影响，仍有章节标记或线路图节点引用时不能删除。

## 数据

```ts
type Props = {
    projectRoot: string | null;
    snapshot: OutlineWorkbenchSnapshot | null;
    foreshadowing: OutlineWorkbenchForeshadowingResponse | null;
    /** 已过格数只显示这个方案的结果 */
    planId: string | null;
    /** 写入成功后重新读取快照 */
    refresh: () => Promise<void>;
};
```

没有 emits、slots 和 expose。

## 状态

- 没有伏笔：左栏显示空状态。
- 未选伏笔：右栏显示空状态。
- 状态接口读取失败：标签只按定义显示“草稿”或“已确认”，不在客户端推断埋设进度。
- 请求失败：错误条显示服务端原因，可关闭；本地输入保留。

## 定时器

自动保存的防抖定时器由 `useOutlineAutosave` 持有，组件卸载时清除；卸载前还有未保存修改时会先尝试保存一次。

## 不支持

- 不合并冲突。
- 不在这里编辑伏笔标记；标记在大纲库的章节大纲正文里添加。
