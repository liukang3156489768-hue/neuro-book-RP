# 大纲库面板

大纲工作台“大纲库”页的宿主。左侧是当前方案的条目树，右侧直接编辑选中的条目：总纲、卷纲、章节大纲、细纲都用同一张表单（`OutlineEntryForm`），没有查看态与编辑态之分，改动自动保存。面板负责所有写入请求：自动保存、另存共用条目、新建、采用、排序、移动、挂载、删除和方案管理。

## 布局

顶部是方案栏（选择方案、新建、重命名、删除方案），其下依次是可选的方案名称输入行、错误条、“未保存修改”切换提示和删除影响面板。主体左右两栏：左栏条目树与“未归入方案的条目”，右栏是选中条目的状态行（类型、采用状态、共用情况、保存状态、上移下移）、需要确认时的提示条、条目表单和条目操作按钮。细纲在最下方附分析面板。`390×844` 下两栏改为上下排列，条目树限高滚动。

## 交互

- 自动保存：停止输入约 1 秒、或焦点离开表单时保存。保存状态显示在状态行：会自动保存、有未保存的修改、正在保存、已保存、暂未保存（附校验原因）、确认后保存、保存失败（可重试）、条目已在别处修改。
- 已有关联新信息的条目修改正文后，先在表单中核对并确认新经历、关系或物品地点信息。自动保存和另存为本方案条目均明确提交核对后的关联信息；移除全部关联信息同时撤下对应记录，基础素材不变。
- 需要确认的修改：有改动时在表单上方出现提示条，确认前不保存。
  - 已正式采用的条目：保存后回到草稿，点“保存并回到草稿”确认。
  - 同时用于多个方案的条目（含手动关联共用的总纲）：不能原地修改，只能填写新标题（预填“原标题（方案名）”）另存为当前方案专属条目，成功后选中新条目。
  - 每条提示都可以“撤销修改”，回到服务端内容。
- 版本冲突：自己保存后刷新回来的新版本不会打断输入；条目在别处被改时，本地没有修改就直接载入新内容，有修改则提示冲突，可“载入最新内容”丢弃本地修改。
- 切换条目或方案前先保存；保存不了时出现提示条，可以留在当前条目，或放弃修改再切换。
- 新建：每个方案新建时自带一个空总纲；选中条目后按层级出现“新增卷纲”“新增章节大纲”“新增细纲”，点击即以草稿创建“新×××”、选中并全选标题，作者接着改名写正文。
- 采用、排序、移动前先保存；本地有未保存修改时这些按钮和细纲分析暂不可用。
- 细纲的“正式采用”交给下方分析面板：先做偏差分析，没有偏离和冲突就直接采用；有则停在分析面板，作者确认偏离、说明冲突处理后点“正式采用细纲”。所属章节大纲未采用或细纲结构还有阻断问题时按钮不可点，按钮下方写明原因。
- 不在当前方案中的条目只读，并提示加入方案后才能编辑。
- 总纲的共用关系：选中总纲时，若有其他方案的总纲，可在“改用其他方案的总纲…”中选择并点“关联总纲”（当前总纲有正文时带 `confirmReplace`）；总纲被多个方案共用时出现“解除共用”，为当前方案分叉出专属总纲。
- 删除总纲：仍被方案使用时只提示使用它的方案、不可确认；未被使用的孤立总纲须勾选二次确认。
- 删除方案：先检查固定线路；确认后删除方案及其专属条目树和方案线路，共用条目保留，事务失败可从操作记录撤销。
- 外部定位：`focusRequest` 每出现一个新的 token，就按“切换条目”的规则选中该条目；条目已不存在时出现提示“要打开的条目已不存在”，可关闭。写作视图的“在大纲工作台中打开”经工作台弹窗走这里。

## 数据

```ts
type Props = {
    projectRoot: string | null;
    snapshot: OutlineWorkbenchSnapshot | null;
    libraryTrees: readonly OutlineWorkbenchLibraryTree[];
    /** 写入成功后重新读取快照 */
    refresh: () => Promise<void>;
    /** 外部要求定位的条目；token 每次请求递增 */
    focusRequest?: {entryId: string; token: number} | null;
};
/** v-model:planId，当前方案 */
planId: string | null;
```

没有 emits、slots 和 expose。

## 状态

- 没有方案：左栏显示“还没有方案”空状态，“新建方案”始终可用。
- 没有方案：左栏显示新建方案的空状态。
- 未选条目：右栏显示空状态。
- 请求失败：错误条显示服务端原因，可关闭；失败不刷新快照，本地输入保留。

## 定时器

自动保存的防抖定时器由 `useOutlineAutosave` 持有，组件卸载时清除；卸载前还有未保存修改时会先尝试保存一次。

## 不支持

- 不合并冲突；冲突时只能丢弃本地修改后载入最新内容。
- 共用条目不能原地修改所有方案，只能另存为当前方案专属条目。
