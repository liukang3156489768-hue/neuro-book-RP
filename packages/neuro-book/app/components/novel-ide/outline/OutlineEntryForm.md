# 大纲条目表单

大纲库里总纲、卷纲、章节大纲和细纲共用的直接编辑表单。没有查看态：条目选中后标题、正文和交接资料都可以直接改，改动写回 `v-model`，由宿主自动保存。

## 布局

自上而下：

1. 标题输入框。
2. 细纲可编辑时有一行工具：正文为空时是「插入细纲模板」，否则是「插入场景」。
3. 富文本正文（`OutlineRichTextEditor`），细纲与章节大纲在正文上方给一句用法提示。
4. 细纲：正文下方列出结构问题（阻断项与提示分色），以及可展开的「章节大纲的伏笔标记」清单，供填写场景伏笔的标记 ID。
5. 章节大纲：交接资料。目标字数与素材索引并排一行，然后是整体写作指导和参考资料列表。
6. 条目已有关联新信息时，显示独立编辑区：对象路径和类别只读，信息正文可修改或移除。所有层级均可显示，与章节交接资料无关。

`390×844` 下并排的字段和参考资料行都改为单列。

## 交互

- 「插入细纲模板」把正文换成细纲模板，章节标题取当前标题。
- 「插入场景」在「禁止事项」之前插入下一个编号的场景模板；没有禁止事项时接在末尾。
- 结构问题随正文实时更新，与服务端分析、采用和写作使用同一份检查（`shared/outline-detail-structure.ts`）。
- 焦点离开整个表单时发出 `commit`，宿主据此立即保存；焦点移到正文的浮动菜单不算离开。
- 修改大纲正文后，若仍有关联新信息，需核对内容并勾选「已核对关联新信息与当前正文一致」才可保存。换选条目加载资料不算正文修改；移除全部关联信息会明确清除对应记录。

## 数据

```ts
type Props = {
    /** 是否显示交接资料；只有章节大纲为 true */
    withMetadata: boolean;
    readonly?: boolean;
    /** "detail" 细纲模板工具与结构检查，"chapter" 伏笔标记，默认 "none" */
    annotations?: "detail" | "chapter" | "none";
    foreshadowOptions?: readonly Readonly<{value: string; label: string}>[];
    /** 细纲所属章节大纲里的伏笔标记，用来检查场景伏笔的标记与状态 */
    chapterMarkers?: readonly ChapterForeshadowMarker[];
};
/** v-model，见 OutlineEntryFormValue */
form: OutlineEntryFormValue;

type Emits = {commit: []};

type Exposed = {
    /** 聚焦并全选标题，新建条目后方便直接改名 */
    focusTitle(): void;
    focusBody(): void;
};
```

没有 slots，attrs 透传到根元素。

## 状态

- 只读：所有字段可看不可改，不显示模板工具和添加、移除按钮；用于不在当前方案里的条目。
- 关联信息对象和类别始终只读；只能维护现有记录的正文或移除，不提供新建对象或新增关联信息入口。
- 细纲正文为空：不显示结构问题。

## 不支持

- 不保存；保存与冲突处理由宿主负责，提交前的形状检查见 `validateEntryForm`。
- 细纲没有段落标注，也没有字段卡片；写作信息全部按模板写在正文里。
