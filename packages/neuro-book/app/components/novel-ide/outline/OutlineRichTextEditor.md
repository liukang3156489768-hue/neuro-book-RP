# 大纲富文本正文编辑器

大纲库（总纲、卷纲、章节大纲、细纲）和伏笔库共用的正文编辑器。正文以 Markdown 保存，编辑时直接呈现标题、列表、强调，以及正文里的伏笔标记、写作指导和段落参考。没有查看态与编辑态之分：能编辑的条目打开就能改，改动通过 `v-model` 交给宿主自动保存。

标注只在所属层级开放：细纲可以加写作指导和段落参考，章节大纲可以加伏笔标记，其他层级的正文只显示已有标注、不提供新增入口。标注的合法性规则（不能跨段落、同类不能嵌套或交叉、写作指导与段落参考只能完整包含、格式与标注只能完整包含）在添加前拦截，规则实现见 `outline-rich-text.ts`。

## 布局

一个带边框的正文区，高度随内容增长，最少约六行。正文为空时显示占位提示。

选中文字或把光标放进已有标注时，在选区上方弹出浮动菜单：

- 选中文字：加粗、斜体；细纲另有“写作指导”“段落参考”，章节大纲另有“伏笔”。点“伏笔”在菜单内展开选择区：上方切换埋设、强化、回收，下方列出伏笔库中的伏笔，点一条即完成标记。伏笔库为空时显示去伏笔库新建的提示。
- 光标在标注内：每个标注一行，写明类型和对象（伏笔显示伏笔名称）。伏笔标记行可以切换动作、改指向的伏笔、移除标记；写作指导与段落参考行可以“填写说明”（交给宿主定位对应卡片）和移除标注。移除只去掉标注，文字保留。
- 操作被规则拒绝时，菜单底部显示原因。

`390×844` 下浮动菜单自动换行并受视口边距约束。

## 交互

- 输入即更新 `v-model`；外部把 `modelValue` 改成与上次发出值不同的内容时，编辑器按新内容重载，不触发更新。
- 打开后未改动或改动后撤销回原样时，发出的值就是传入的原文，不会因为序列化差异产生虚假修改。
- 伏笔标记使用标记色下划线区分动作：埋设为成功色、强化为警示色、回收为强调色；写作指导为浅色底，段落参考为点状下划线。
- 回车拆开标注、粘贴带同一 marker 的文字时，同一 marker 只保留第一段，其余碎片去掉标注、保留文字。

## 数据

```ts
type Props = {
    /** Markdown 正文，受控 */
    modelValue: string;
    /** 可新增的标注类型；默认 "none" */
    annotations?: "detail" | "chapter" | "none";
    /** 章节大纲可选的伏笔；label 用于菜单列表与标注名称 */
    foreshadowOptions?: readonly Readonly<{value: string; label: string}>[];
    placeholder?: string;
    readonly?: boolean;
    ariaLabel?: string;
};

type Emits = {
    "update:modelValue": [value: string];
    /** 新增了写作指导或段落参考，宿主据此把对应说明卡片带到眼前 */
    annotate: [kind: "guidance" | "reference", marker: string];
    /** 在浮动菜单里点了“填写说明” */
    "focus-mark": [kind: "guidance" | "reference", marker: string];
};

type Exposed = {
    focus(): void;
    /** 选中某个标注的文字并滚动到可见位置；找不到时不做事 */
    selectMark(kind: "guidance" | "reference" | "foreshadow", marker: string): void;
    /** 移除标注、保留文字 */
    removeMark(kind: "guidance" | "reference" | "foreshadow", marker: string): void;
};
```

没有 slots，attrs 透传到根元素。

## 状态

- 只读：内容可选中、不可编辑，不弹浮动菜单。
- 选区与标注部分重叠时加粗、斜体按钮禁用，悬停说明原因。

## 渲染目标

浮动菜单挂到最近的主题宿主（`THEME_HOST_SELECTOR`），使弹层继承当前主题并不被对话框的溢出裁切；找不到主题宿主时挂到 `document.body`，此时仍能操作，但颜色按根主题显示。

## 不支持

- 不保存；自动保存、版本冲突和门禁确认由宿主负责。
- 行内的普通 HTML 注释（例如句中的 `<!-- 备注 -->`）在富文本里无法表示，保存时会丢失；独立成段的注释按源码块保留。
- 不提供标题、列表按钮；可用 Markdown 快捷输入（`# `、`- `、`1. `、`> `）。
