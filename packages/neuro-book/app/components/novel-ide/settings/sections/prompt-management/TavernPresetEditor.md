# TavernPresetEditor

原生酒馆预设的受控编辑器。按全局提示词顺序展示启用状态、名称、角色及正文，资料条目编辑绑定消息；未排列条目可加入序列。修改保留源 JSON 的未知字段，开关与排序均随预设显式保存。扩展脚本只显示为源数据，由服务端预览报告支持情况。

每个写作条目可切换“直接排序”或“变量映射”。直接排序创建独立条目进入全局序列，正文使用写作动态变量，可编辑角色、模板、触发和位置；内容只经过写作模板渲染，不参与酒馆变量初始化。切回映射移除该直接条目及所有顺序引用，恢复之前选择的映射目标（没有记录时采用默认目标），失效目标仍保留并提示；直接模板改动保存为休眠草稿，再切回直接排序恢复模板和设置，以新条目加入序列末尾。休眠草稿不参与编译，完整配置与快照保留；单条或批量删除直接条目时连同休眠草稿清除。两条路径互斥；删掉直接条目使写作条目回到未映射，必需项由保存校验保护。

序列和未加入序列的条目均提供多选框、单条删除；工具栏支持全选全部源条目和批量删除。删除从 prompts 和所有 prompt_order 中清除，并删除同名资料绑定；映射到被删除资料目标的选择保留为失效提示。移出序列仍只移除全局顺序，不删除源条目。全部操作作用于未保存草稿，不影响历史快照。

序列手柄支持左键或触屏指针拖动，键盘上下键也可移动；拖动已选条目时按原相对顺序移动当前序列中的选中组，未排序条目不参与拖动。指针由稳定序列容器捕获，结束、取消和失去捕获均清理拖动状态。保存期间禁止选择、拖动、切换和删除。

写作条目映射按文风、章节上下文、人物资料和场景要求分组，每条显示原模板和目标下拉；职责与输出要求不参与映射。目标自动扫描当前源 JSON 的资料占位符、固定名局部／全局变量，停用或仅定义未读取的字段标记不可用；动态变量名显示提示，不猜测目标。多个条目映射到同一字段时按原模板顺序合并。处理顺序为预设变量初始化、写作映射、提示词展开；初始化副作用只执行一次，映射后展开读取最终变量。保存和预览均检查必需条目实际进入消息，缺失或裁剪明确报错。缺失目标保留选择并显示错误，不自动改到其他字段。

旧配置仍使用旧绑定；点击“启用写作条目映射”才显式转换已知原模板内容并保留其他手工绑定。完整配置导出包含映射；原生导出只包含酒馆源 JSON。绑定 JSON 的未应用输入不被映射操作覆盖。

正文输出可保留处理后的完整回复，或提取指定标签中的正文；质检开关控制写手正文规则检查。原生生成参数在源 JSON 中编辑并在预览中检查。新建普通条目以唯一标识加入全局顺序，移出序列保留原条目数据，便于再次加入。

生成参数覆盖 JSON 经严格字段校验后显式应用，仅覆盖指定参数；空对象使用预设默认。预览显示编译参数，实际请求由运行时按选定模型接口适配。

首次启用没有绑定的资料条目时只补该槽位的空消息数组，已有身份、槽位和变量初值保持原样。必需作品变量必须绑定到已启用资料槽位；缺失时由保存或预览返回原因。

普通条目展开后可设置顺序插入或历史深度插入、深度和同深度顺序，以及原生生成类型触发条件。数字输入为空时恢复酒馆默认字段；无效整数不写入草稿。触发条件以逗号分隔，空列表表示不限生成类型。资料槽位继续使用绑定消息，不能切换为普通深度注入。全局生成模式决定本次预览和写手调用采用普通生成或续写。

宏引擎选择只展示共享合同支持的旧引擎与新引擎，用户应与酒馆设置保持一致；切换不修改原生源 JSON 或插件数据。缺少必需宏环境由编译预览明确报错。

请求后处理可沿用原生预设设置，或显式覆盖为原生支持的后处理类型。新宏环境可在绑定 JSON 的 nativeContext 中提供，绑定编辑不会自动填入机器时间或随机种子。

编辑器明确提示插件字段原样保留但不执行。编译成功后报告分别展示原生提示词支持情况、未支持机制和已登记的插件依赖，提示词可编译不代表插件已运行；未支持项不冒充完整兼容。

上下文预算默认关闭，保持完整提示词。用户开启后必须选择分词方式、填写包含输出的总预算并显式应用；不从预设的最大上下文自动推断模型窗口。“优先保留示例”仅使示例先于历史分配预算，无法容纳完整示例组时仍不发送该组。预算可裁剪历史消息（含深度注入候选）和示例，普通提示条目保持完整；必需小说字段的所有副本均被裁剪后，写手会拒绝发送，避免丢失写作任务。contextTokens 控制原生消息选择预算；报告的编排占用含 priming、不含输出，计数发生在 system 合并及服务端后处理之前，后处理可能增加名称或占位消息，最终请求仍受真实模型窗口限制。用户应将总预算设在选定模型的窗口内。关闭会从绑定中移除预算设置。

工具栏、序列、身份、资料和变量、原生 JSON、编译预览分段展示并随宿主内容区共同滚动；390px 下工具栏和条目控制自动换行，正文与 JSON 在区域内滚动。上下移动按钮可通过键盘操作。原始 JSON 输入只有“应用 JSON”成功后才替换受控草稿，解析失败保留输入和既有草稿。

```ts
type Props = {
    modelValue: TavernWriterPreset; // 受控草稿，不直接修改
    purposeId: string;
    disabled?: boolean; // 默认 false
    preview?: (request: TavernPreviewRequest) => Promise<TavernPreviewResult>;
    download?: (name: string, contents: string) => void;
    name: string;
};
type Emits = {'update:modelValue': [value: TavernWriterPreset]};
```

无 slots 或 expose；attrs 默认透传根元素。预览和下载均通过宿主能力，预览不调用模型、不保存配置或变量。原生 JSON 导出可供酒馆读取，完整配置导出另含 NeuroBook 的身份、绑定及变量设置。预览使用手工填写的变量示例，真实作品数据在写手调用时注入。改变草稿使旧预览失效；请求期间后续改动不会被旧结果覆盖。
