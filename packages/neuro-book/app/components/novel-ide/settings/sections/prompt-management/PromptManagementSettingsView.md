# PromptManagementSettingsView

全局提示词管理的受控视图，按设计工作台、大纲规划工作台、写作模块展示调用用途和预设。内置默认预设永久只读，用户可以复制它新建自己的预设。行为合同见 [提示词管理](../../../../../../../../docs/specs/ui/prompt-management.md)。

## 布局

标题、搜索与模块筛选、编辑工具栏和底部保存操作固定，列表或编辑内容占据剩余高度并独立滚动。提示词条目依次展示拖动手柄、名称和展开操作、角色选择、启用开关与删除，展开后展示名称和正文输入、右下角保存。停用条目标记“已停用”，仍可展开、编辑和排序。内容宽度不足 760px 时用途名称与预设操作分行；390px 下工具栏和预设名称换行，正文纵向滚动，没有页面水平溢出。

## 交互

预设选择立即保存，写手下一次调用使用最新预设；其他用途仅影响后续新会话和任务。新建复制当前预设，保存前不增加正式预设。内置默认可查看和复制；名称、正文只读，角色、拖动、新建条目、删除和保存禁用。自定义预设支持编辑、删除确认。条目左键按住手柄拖动排序；手柄聚焦后方向键上下移动。条目按钮控制展开与折叠，文本输入遵循原生键盘行为。

正文底部保存和底部保存预设均原子提交当前预设全部改动，包括条目启用状态。写手场景正文和局部改写的已保存条目开关独立即时保存，只提交开关状态，并更新草稿并发基线；正文、名称、角色、顺序等未保存修改保持草稿。写手新预设和新条目须先保存再使用开关。其他用途的开关只改草稿，随预设显式保存。内置开关只读，保存中禁用开关；新条目默认启用，缺少启用字段的旧条目按启用展示。离开编辑页或组件销毁丢弃全部未保存修改，保留已即时保存的开关状态。保存失败保留草稿并显示原因，不冒充保存成功。必需变量只能由已启用条目提供，否则保存被拒绝。点击返回时焦点返回当前用途的查看/编辑按钮；进入编辑时聚焦预设名称。

## 数据

```ts
type Props = {
    catalog: PromptCatalogDto; // 宿主已校验的完整目录，受控，不在视图中修改。
    saving?: boolean; // 默认 false，保存期间锁定操作。
    mutate: (mutation: PromptMutationDto) => Promise<PromptCatalogDto>;
    preview?: (request: TavernPreviewRequest) => Promise<TavernPreviewResult>;
    download?: (name: string, contents: string) => void;
};
```

`mutate` 是宿主传入的可替换持久化能力；视图以目录 revision 提交并发保护条件，成功后以返回目录更新草稿，失败保留当前编辑状态。没有 emits、slots 或 expose。attrs 按 Vue 单根默认透传到根元素；加载与读取失败由设置外壳统一处理。

写手用途提供“导入酒馆”按钮，读取用户选择的本地 JSON 为草稿，保存后才切换实际预设。原生 JSON 首次导入生成按写作条目配置的映射，排除职责与输出要求；完整配置导入保留身份、绑定、变量和映射设置。旧配置未开启映射时保持旧绑定，可显式启用映射。酒馆预设使用独立编辑器，支持原生顺序、角色、正文、启停及绑定 JSON，所有更改显式保存；保存已有预设沿用身份并增加版本。导出与编译预览能力由宿主传入，编译预览不调用模型。导入不会执行附件脚本。

新配置的运行时发送按完整条目序列处理，OpenAI Chat Completions / Responses 保留 system/user/assistant 的交错顺序和独立边界。其他接口不能表达多条或交错 system 时明确报错；历史会话继续按其快照的原发送格式执行。本组件只编辑序列，不自行调整角色或为某个接口重排条目。

## 状态与边界

默认展示已实装提示词及当前预设；搜索无结果显示空状态。内置查看标记“内置默认 · 只读”，自定义编辑显示未保存或当前版本。保存和删除失败使用局部反馈；读取错误由宿主展示。动态变量提示保持模板字面文本，不插入当前作品内容；正文中的动态变量由运行时替换。本页可编辑酒馆生成参数及其显式覆盖，不调用模型、不变更权限、不管理项目级覆盖、不读取浏览器存储。
