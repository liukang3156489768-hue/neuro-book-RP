# 写作大纲视图

左栏“大纲”容器里的视图，是写作界面的入口：顶部选择写作方案与文风，下面是按方案层级组织的章节树。树本身由 `WritingOutlineTree` 渲染，本视图负责载入、错误恢复，以及把树发出的意图交给写作 store 执行。与大纲工作台不同，这里不编辑规划，章节状态和问题都只显示服务端给出的结果。

## 布局

自上而下：

1. 设置区：”写作方案”选择；下面一行是”文风”选择，右侧依次是”编辑当前文风”（铅笔图标）、”新增文风”（加号图标）、”删除当前文风”（垃圾桶图标）。设置文件格式错误、方案已不存在或大纲不可读时，这里多一条提示。
2. 新增或删除确认：点”新增”后在设置区下方内联显示名称输入框与”创建 / 取消”按钮；点”删除”后在同一位置显示确认信息”删除文风”xxx”？可在文件历史中恢复。”与”删除 / 取消”按钮。
3. 未选文风且未在操作时的提示：”写作前需要选择文风；没有合适的可以点”+”新增。”
4. 问题记录读取失败时的提示条。
5. 滚动区：章节树。

设置区固定，滚动区伸缩。`390×844` 下选择框占满整行，不产生横向滚动。

## 交互

- 切换写作方案或文风立即写入写作设置；失败时弹出错误通知，选择回到原值。
- "编辑"在中间编辑器里打开当前文风文件；未选中文风时按钮不可点。
- "新增"：在选择框下方内联显示名称输入框、"创建"和"取消"；回车或点"创建"后新建文风文件，建好后在编辑器打开，并刷新文风列表；未选文风时顺带选中新文风。确认删除时收起新增表单。输入框为空时"创建"按钮不可点。
- "删除"：在同一位置内联显示确认信息、"删除"和"取消"；确认后删除文风文件并刷新列表，删的是当前文风时同时清空选择。未选文风或有写作运行进行中时按钮不可点、title 写明原因。新增表单打开时收起确认框。
- 树上的选择、展开、关联、解除关联、忽略问题与跳转都交给写作 store。
- 规划或正文文件变化时，store 自动刷新，展开状态与选中项保留。

## 数据

没有 props、emits、slots 和 expose；视图由工作台按描述符创建，数据全部来自 store。attrs 透传到根元素。

读取 `useWritingWorkspaceStore`：`overview`、`issues`、`issuesError`、`styles`、`loading`、`error`、`selectedKey`、`collapsedVolumes`、`expandedChapters`、`lockedChapters`、`activeRuns`。

写入与请求：`ensureLoaded`、`refresh`、`select`、`toggleVolume`、`toggleChapter`、`setPlan`、`setStyle`、`createStyle`、`openStyle`、`deleteStyle`、`linkProse`、`unlinkProse`、`ignoreIssue`、`openInOutlineWorkbench`。

## 状态

- 首次载入：`role="status"`、`aria-busy` 的载入提示。
- 载入失败：`role="alert"` 显示原因与“重试”；已打开的正文不受影响。
- 未选写作方案：只显示方案选择和一句说明，没有树。
- 方案已不存在或大纲不可读：提示原因；大纲不可读时已有正文仍列在”未关联正文”中。
- 写入中：选择框与树上的写入按钮禁用；文风操作按钮也禁用。
- 未选文风且未在新增：在文风选择下方提示”写作前需要选择文风；没有合适的可以点”+”新增。”

## 不支持

- 不新建、删除、改名或拖动大纲条目。
- 不读取也不显示线路规划和伏笔。

## 注意事项

- 本视图与写作会话视图都是写作领域的入口，但领域数据只有写作 store 一份，两者都从它读写，不存在两个真相源。

## 隐藏通道理由

- `state:shared-read` / `state:shared-write`：视图由工作台按描述符创建，没有父组件传 props；选中项与展开状态要与中间页、右栏会话共享，只能放在写作 store。
- `io:read` / `io:mutate`：请求经 store 里的写作 API 客户端，fetch 可注入，测试据此替换。
