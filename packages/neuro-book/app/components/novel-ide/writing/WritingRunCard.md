# 写作进度卡片

写作会话里的一张卡片，显示一次整章写作或局部改写的进度。数据是服务端从运行记录投影出的进度，刷新页面后按同一份记录恢复；卡片只把用户的停止、继续和确认意图发给宿主，自己不发请求。与普通消息卡片不同，它区分整章写作与改写两种形态：整章写作逐场景显示状态并能展开查看写手提示与审阅结果，改写显示新旧段落对照并只允许操作一次。

## 布局

自上而下：

1. 标题行：运行类型（写作本章、续写、改写）与状态徽标，右侧是“停止”或“继续”。
2. 连接中断或运行出错时的提示条。
3. 主体：
   - 整章写作：准备完成即显示整章场景列表，每行是场景标题与状态，可展开；区分待规划、规划中和规划已确认后的待写。准备结果尚未返回时显示“正在规划场景”。
   - 改写：修改要求、原文与改写后的对照。
4. 待确认区：讨论模式的当前场景规划摘要与“确认场景”“退回修改”，或改写的“替换”“放弃”。
5. 结果区：运行结束后的说明、字数与提示。

标题、场景标题和对照正文都允许换行，不产生横向滚动；`390×844` 下按钮换到下一行。展开后的场景详情、写手提示、场景规划摘要以及结果区的问题与提示列表都在各自的限高区域内纵向滚动。

## 交互

- 点场景行展开或收起，展开后只读查看每次尝试的写手提示和审阅结果。
- “停止”：运行中或等待确认时可用。
- “继续”：只在这一章最近一次运行已停止、失败或进程中断时可用；已确认规划沿用，未完成的规划先完成，再续写未通过的正文。
- “确认场景”直接应答；“退回修改”需要先在意见框写明意见。确认仅推进到下一个场景规划，所有规划确认完成才开始正文写作。自动模式由独立审核模型推进，不显示人工确认控件。
- “替换”“放弃”点过一次后两个按钮都禁用，不等服务端返回。
- 主创核对场景规划时卡片只显示“等待主创核对”，不提供按钮：这一项只由主创应答。

## 数据

```ts
type Props = {
    /** 运行进度，受控 */
    progress: WritingRunProgressDto;
    /** 是否为这一章最近一次运行；只有最近一次可以继续。默认 false */
    latest?: boolean;
    /** 进度轮询失败，显示“连接中断”。默认 false */
    connectionLost?: boolean;
    /** 宿主正在处理这张卡片上的操作，按钮全部禁用。默认 false */
    pending?: boolean;
};

type Emits = {
    stop: [runId: string];
    continue: [chapterEntryId: string];
    answer: [runId: string, key: string, decision: WritingUserDecision];
};
```

没有 slots，没有 expose，attrs 透传到根元素。

## 状态

- 运行中：徽标“运行中”，场景状态随进度更新。
- 等待确认：徽标“等待确认”。
- 进程中断：徽标“已中断”，可以继续，也可以停止。
- 连接中断：提示条显示“连接中断，恢复后自动补齐进度”，按钮保持原样。
- 运行出错：提示条显示服务端给出的原因。
- 改写因目标段落已被改动而停止：结果区以错误样式说明替换失败，正文不变。

## 不支持

- 不能从卡片发起新的写作或改写，只能经主创。
- 不渲染 Markdown，场景规划摘要按原文换行显示。
- 不显示续写沿用的上一次运行里已通过场景的尝试记录。
