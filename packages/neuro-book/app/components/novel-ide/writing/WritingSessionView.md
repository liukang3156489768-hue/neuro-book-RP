# 写作会话视图

右栏“写作”容器里的视图，是左栏所选章节的主创会话。一章可以有多个会话，由服务端按章节查找或创建，Profile 固定为主创；这里复用项目现有的对话流、输入框和待确认面板，只加写作需要的限制，不另建会话界面。头部可以切换、新建、删除本章会话，底部通过 `WritingRoleModelsPopover` 设置三个写作角色的模型；没有模式切换，并在对话下方显示默认折叠的写手输出和这一章的写作进度卡片。

## 布局

自上而下：

1. 头部：当前章节标题与写作状态；不可写时在标题下列出原因。下面一行是会话控件：会话下拉（没有会话时显示“还没有会话”）、“新建会话”“删除当前会话”两个图标按钮；删除确认内联显示在这一行下方。
2. 滚动区：对话流，下面接写手输出条目和这一章的“写作进度”抽屉。写手输出按运行、场景与尝试区分，默认折叠，展开后思考与正文各自限高滚动。默认只显示最近运行；展开更早运行也显示其写手条目。进度抽屉内容限高约半屏并纵向滚动，卡片再长也不挤掉对话流。
3. 底部：错误提示与输入卡片；主创提出待确认的问题时，由待确认面板替换输入卡片。最下方左侧始终保留模型设置入口。

头部和底部固定，滚动区伸缩。`390×844` 下结构不变，卡片按钮换行，不产生横向滚动。

## 交互

- 左栏选中章节（或它的细纲、正文）后切换到这一章的会话；旧章节运行中的写作不受影响。
- 默认打开这一章最近更新的会话；这一章还没有会话时显示空状态，第一次发送时创建。
- 会话下拉切换到本章其他会话；“新建会话”另开一个并打开，章节不可写时不可点。
- “删除当前会话”先内联确认，确认后归档并改开剩下最近的一个；这一章有写作运行、主创正在回复或等待回答时不可点，按钮提示写明原因。
- 主创回复中、提交待确认中或会话载入中，切换、新建、删除都不可用。
- 模型设置保存了主创设置后，当前会话清掉单独的模型与思考选择，下一轮按新设置；清除失败时弹出通知，设置本身已保存。
- 点“写作进度”展开或收起抽屉，默认展开；收起后有待用户确认的场景规划或改写时，标题旁显示“等待确认”，并自动重新展开。
- 写手条目展开时才读取完整会话内容，正在生成时流式更新；收起、切换章节或卸载时断开其连接。模型没有返回思考内容时显示说明。写手输出只读，未通过审阅的尝试也可查看，不代表已经写入正文文件。
- 对话气泡上的复制、编辑、重新生成和从此处分支按钮均作用于当前写作会话：复制读取完整用户消息，编辑保存后从该节点重新调用主创，重新生成重放该节点，分支只移动当前活动路径；运行中或会话不可修改时，涉及历史变更的按钮会被禁用。
- 发送后请 store 尽快读一次运行记录，主创刚发起的写作能立即出现卡片。
- 发送按钮在主创运行时变为停止，停止的是这次对话，不是写作运行；停止写作运行用卡片上的“停止”。
- 左栏“开始写作”和编辑器“改写选中内容”经 store 把文字预填进输入框；开始写作会直接发送，改写等用户补写修改要求。
- 不可写章节仍可查看历史会话与卡片，但输入框只读并显示原因。

## 数据

没有 props、emits、slots 和 expose；视图由工作台按描述符创建，数据全部来自 store。attrs 透传到根元素。

读取 `useWritingWorkspaceStore`：`selectedChapter`、`chapterRuns`、`runProgress`、`chapterRunsError`、`connectionLost`、`composerDraft`、`lockedChapters`、`projectRoot`。

写入与请求：

- 会话：`useWritingChapterAgent` 读取、列出、切换、新建、删除、创建、发送、中止、提交待确认与跟随角色设置；
- 进度卡片的停止、继续、确认经 `stopRun`、`continueChapter`、`answerRun`；
- `pollSoon` 请 store 提前轮询；`consumeComposerDraft` 标记预填文字已取走；`ensureLoaded` 在首次挂载时载入目录。

## 状态

- 没有选中章节：空状态，提示在左侧大纲中选一章。
- 会话载入中：滚动区显示 `role="status"` 的载入提示。
- 会话载入失败：底部 `role="alert"` 显示原因与“重试”，左栏和中间照常可用。
- 运行记录读取失败：卡片区 `role="alert"` 显示原因与“重试”。
- 卡片操作失败：弹出错误通知，卡片保持原样。
- 会话切换、新建或删除失败：弹出错误通知，停留在原会话。
- 输入框只读：主创运行中、提交待确认中，或章节不可写。

## 不支持

- 不能切换 Profile 或模式；模型只按角色设置，不做单个会话的模型覆盖。
- 会话列表只列本章会话，不列其他章节或非写作会话。
- 不能从界面直接发起写作或改写；都经主创。
- 不显示其他章节的进度卡片。

## 注意事项

- 预填文字只在会话载入完成、且属于当前章节时取走；章节切换途中到达的预填会等新会话就绪。
- 进度卡片按运行记录轮询，不走会话流；会话流只承载对话本身。

## 隐藏通道理由

- `state:shared-read` / `state:shared-write`：视图由工作台按描述符创建，没有父组件传 props，选中章节与运行进度只能从写作 store 取；写入只有预填文字的取走标记和轮询请求。
- `io:read` / `io:mutate` / `io:stream`：会话读取、发送与事件流经 `useWritingChapterAgent`，其请求入口是可替换的 `useAgentSessionApi`；运行操作经 store 的写作 API 客户端，fetch 可注入。
