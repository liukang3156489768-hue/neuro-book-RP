# 写手输出

写作右栏对话区域中的只读折叠条目，显示某次场景写作或局部改写的写手输出。标题区标明场景、尝试次数和状态，默认关闭；展开后分别显示模型返回的思考内容与正文，两处各自限高滚动，长输出不会撑掉输入区。

## 布局与交互

标题始终可见，支持点击、Enter 和 Space 展开或收起。展开时读取该运行关联的写手会话；正在生成的输出通过会话事件流更新，结束后读取完整已保存内容。收起或卸载时释放事件流；切换来源时丢弃旧请求结果。390px 下标题、状态和正文换行，展开内容不产生横向滚动。

## 数据

```ts
type Props = {
    projectRoot: string;
    runId: string;
    title: string;
    attempt: WritingAttemptDto;
    /** 本次尝试可能仍在生成；默认 false。 */
    active?: boolean;
};
```

无 emits、slots 或 expose；attrs 透传根元素。开合状态仅在内存保存，不影响模型和运行。

## 状态与边界

- 收起时不读取会话内容，不建立事件流。
- 读取失败显示错误与重试，已存在的运行正文仍可查看。
- 模型没有返回思考内容时显示说明，不生成额外思考。
- 历史尝试缺少会话关联时使用运行记录正文，并说明思考不可用。
- 内容只读；生成正文包括未通过审阅的尝试，不代表已经写入正文文件。

## 隐藏通道理由

`io:read`、`io:stream`：由本条目拥有的只读 composable 按需读取所属运行的写手内容并消费现有 Agent SSE；不创建、调用或修改任何会话。生命周期结束时关闭连接。
