# NovelIdeSettingsDialog

设置宿主，保留启动配置、全局配置、项目配置和浏览器状态四个作用域。

## 布局

桌面弹窗宽高约为视口的 82%，占约三分之二面积。标题与作用域、保存操作固定，左侧分类独立滚动，右侧设置内容独立滚动。底部版本信息位于导航末尾。

Agent Profile 页面在大屏填充右侧内容区的剩余高度，标题固定，Profile 导航和参数表单各自滚动；其内容不能越过内容区覆盖弹窗标题、分类或保存操作。小屏沿用内容区整体滚动。

390×844 下弹窗两侧至少留 12px；作用域横向滚动，保存操作换行，分类变为横向列表，右侧内容填满剩余高度。外观与编辑器表单的选择框换行，避免固定宽度挤出可用区域。

## 交互

选择作用域与分类不切换作品。项目作用域仅在当前作品可用时启用；桌面分类仅在 Desktop Bridge 可用时显示。保存与恢复按钮调用当前面板公开的操作，加载或保存期间阻止切换和关闭；未保存草稿沿用原有离开即丢弃语义。

主题可切换、新建、复制、编辑、导入、导出与删除；主题编辑和删除确认使用原有子弹窗。子弹窗打开时父弹窗不处理 Escape。普通按钮遵循 Tab 和 Enter；当前作用域与分类提供按下状态。窗口关闭与焦点行为由公共 Dialog 承担。

## 数据

必填受控属性 `modelValue: boolean` 控制显示；`update:modelValue` 携带关闭后的布尔值。无外部 slot。子面板的 `dirty`、`loading`、`saving`、`saveSettings` 和 `restoreSettings` 是保存操作的唯一来源。

## 状态

默认进入全局模型设置；保存按钮在无变更、加载或保存时禁用。运行中显示加载图标。版本读取失败显示不可用文字；业务表单保持各自的加载、空数据和错误反馈。全部外壳颜色跟随现有主题变量。

## 不支持

不热更新启动安全配置，不提供设置之外的作品管理，也不在切换分类时自动保存草稿。

## 隐藏通道理由

这是设置宿主，直接读取并更新 Novel IDE store 的主题、推理和编辑器偏好，同时读取作品上下文用于确定配置作用域；这些行为目前尚未上移到调用方。

宿主直接读取 `/api/app/version`。六个配置面板经现有 Config API 读取与保存设置；主题管理经 `useThemeManager` 保存 Global Config。Desktop 设置通过桥接接口读取和更新。设置领域的请求和草稿生命周期由本宿主及既有面板共同承担，外壳调整不改变这些连接。

## 已知偏差

现有版本查询和设置能力未通过 props 注入，属于既有不可替换请求入口；公共 Dialog 的焦点约束和子表单键盘行为依赖各自实现，本文档不宣称已经完成完整的可访问性整改。
