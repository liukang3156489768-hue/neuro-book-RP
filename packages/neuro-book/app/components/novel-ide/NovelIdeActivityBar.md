# 工作台导航

固定窄导航承载书架、文件、角色、剧情、世界、历史、追踪、AI、账户与设置入口。选中项使用主题强调色；空间不足时次要入口进入“更多”。390px 窗口保持导航可见，工作区抽屉在导航右侧覆盖内容。按钮提供名称和键盘焦点，更多菜单支持方向键及 Escape，关闭后返回触发按钮。

所有状态由 props 传入：当前标签、桌面宿主是否可用、作品是否 ready、用户资产模式、AI 面板状态、当前账户；组件只发出对应操作事件，不调用项目或 Agent API。未激活作品时项目功能禁用。账户菜单沿用现有账户事件。

本地状态仅管理更多菜单与可见入口数量。语言从应用注入；尺寸观察与点击外部监听仅用于导航布局和关闭菜单，卸载时释放。组件不负责作品加载、登录及设置保存。
