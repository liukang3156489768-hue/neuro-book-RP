# 大纲提取结果

大纲提取任务产出方案后的结果卡片：说明结果落在哪个方案、提示卷纲和总纲是否过期、列出覆盖失败项与未对应的章节，并提供“打开提取方案”“重新汇总本卷与总纲”两个出口。

## 布局

一张卡：标题行是方案名和去向徽章（新建、补充、覆盖）；其下依次是过期提示条（有才显示）、覆盖失败列表（有才显示）、未对应章节提示（有才显示）、操作按钮行。

## 交互

- “打开提取方案”上报方案 ID 和标题，由宿主决定如何跳转到大纲工作台。
- “重新汇总本卷与总纲”仅在服务端允许时可用（`canResummarize`），点击后宿主重新生成过期的卷纲与总纲。
- 覆盖失败项说明具体章节、类型和原因；这些项的原内容保持不变，可到任务进度里重试。

## 数据

```ts
type Props = {
    outcome: OutlineExtractionOutcome;
    /** 重新汇总请求进行中 */
    busy?: boolean;
};
type Emits = {
    (event: "open-plan", plan: {planId: string; planTitle: string}): void;
    (event: "resummarize"): void;
};
```

没有 slots 和 expose。

## 状态

- 无过期：不显示提示条，“重新汇总”按钮不显示。
- 过期但任务仍在运行或等待输入：显示提示条，按钮不可用。
- `busy`：“重新汇总”按钮转圈。

## 不支持

不在卡片内预览方案内容；查看和编辑请打开大纲工作台。
