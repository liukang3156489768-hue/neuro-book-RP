# 提取提示条

作品提取各面板共用的单行或多行提示条，用颜色区分错误、警告、说明和成功。内容通过默认插槽给出；错误提示以 `role="alert"` 暴露给辅助技术，其余为普通文字。

## 布局

占满父容器宽度，内边距与圆角沿用控件规格；文字自动换行，不会撑出横向滚动。

## 数据

```ts
type Props = {
    /** 默认 info */
    tone?: "danger" | "warning" | "info" | "success";
};
```

插槽：默认插槽放提示内容。没有 emits 和 expose。

## 不支持

不带关闭按钮，也不自行计时消失；提示是否显示由使用方根据状态决定。
