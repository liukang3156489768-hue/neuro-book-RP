# 素材写入结果

确认写入之后逐条说明结果：哪些条目已写入 lorebook、哪些被跳过、哪些失败以及失败原因。失败的条目仍留在待写入清单里，可以修改后再次确认写入，已经写成功的部分不会重复写。

## 布局

顶部一行汇总徽章（已写入 x、已跳过 y、失败 z）；其下每条结果一行：标题、状态徽章、实际创建或覆盖的文件路径；失败项下方是原因。`390×844` 下路径自动换行。

## 交互

纯展示，没有交互。

## 数据

```ts
type Props = {
    report: WriteReport;
};
```

没有 emits、slots 和 expose。

## 状态

- 全部成功：汇总行为绿色，不出现失败说明。
- 有失败项：失败徽章为红色，行内展开原因，并在顶部提示“失败的条目仍在清单中，可修改后再次确认写入”。
- 没有任何结果：不渲染。

## 不支持

不提供撤销已写入文件的入口；已写入的条目请到 lorebook 中修改或删除。
