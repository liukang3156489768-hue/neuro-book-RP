# 素材类别多选

素材提取开始前选择要提取的素材类别，默认九类全选。组件只维护勾选，不发请求。

## 布局

一组复选框，每个类别一项，名称后用说明文字标出“实体”或“文档”类（实体类会在后面进入归类步骤）；右上角有“全选”“清空”。`390×844` 下两列排布，自动换行。

## 交互

- 点击复选框上报该类别的切换；“全选”“清空”分别上报全部类别或空列表。
- 一个类别都不选时，宿主不允许开始提取；组件本身在底部提示“至少选择一个类别”。

## 数据

```ts
type Props = {
    /** 已选类别的 key（角色、势力、物品、地点、特殊规则、文风、世界观、写作手法、素材特点） */
    modelValue: string[];
    disabled?: boolean;
};
type Emits = {
    (event: "toggle", key: string): void;
    (event: "update:modelValue", keys: string[]): void;
};
```

没有 slots 和 expose。类别清单取自共享常量 `MATERIAL_CATEGORIES`，不重复定义。

## 状态

- `disabled`（任务运行中）：全部复选框与按钮不可用。
- 空选择：显示提示，不阻止用户继续勾选。

## 不支持

不支持自定义类别，也不支持调整类别的提取顺序（顺序固定为九类的标准顺序）。
