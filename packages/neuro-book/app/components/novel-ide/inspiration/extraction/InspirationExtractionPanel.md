# 作品提取面板

Inspiration 设计工作台里的“作品提取”页：选一部放在 `reference/` 里的作品，从中提取大纲（细纲、章节大纲、卷纲、总纲）或素材（角色、势力、物品、地点等）。它是这一页的宿主，持有 `useInspirationExtraction` 并把状态分发给各个纯展示组件；大纲提取和素材提取是两个并列入口，各有独立的进度，互不阻塞，可以同时进行。大纲和素材共用来源分块边界，素材可选块，大纲始终覆盖整部作品。

## 布局

自上而下：来源选择（作品文件、刷新）、模型选择；模型选择右侧显示当前入口对应的大纲或素材任务列表、新建和删除操作，列表复用 FormSelect；其后是“大纲提取 / 素材提取”两个入口切换和当前入口的内容。两个入口的内容始终挂载，只切换显示，因此切换时不会丢失正在编辑的划卷、勾选和进度。整页在 Dialog 内竖向滚动。`390×844` 下全部纵向堆叠，不出现横向滚动。

## 交互

- 选择作品后同时加载章节预览、已有方案（数据去向）和该作品最近的大纲与素材任务；有未完成的任务会自动恢复进度。
- 两类任务列表分别显示当前来源的全部对应任务；选择任务后显示对应进度和产物，点击“新建”进入全新的提取设置。大纲新任务恢复默认切分、划卷与新建方案去向。
- “删除”需确认，运行中的任务先停止并等待收尾，再删除记录和临时产物。已写入的大纲方案、条目及素材文件保留；删除期间管理控件禁用，失败保留任务并显示原因。
- 任务运行期间每隔几秒读取一次进度，任务停止、完成、等待确认或面板关闭后立即停止轮询。
- 大纲结果卡上的“打开提取方案”向上转发 `open-outline-plan`，由页面关闭本窗口并打开大纲工作台。
- 所有写入类操作的“确认者”都由服务端固定为用户，本面板不提交也不显示身份。

## 数据

```ts
type Props = {
    projectRoot: string | null;
    /** 可选的提取模型；缺省走服务端默认模型 */
    modelOptions?: Array<{key: string; label: string}>;
    /** 当前选择的模型 key，undefined 表示跟随默认模型 */
    modelKey?: string;
    /** 请求入口，缺省使用全局 $fetch；测试可替换 */
    api?: ExtractionApi;
    /** 进度轮询间隔，缺省 2000 毫秒 */
    pollIntervalMs?: number;
};
type Emits = {
    (event: "update:modelKey", key: string | undefined): void;
    (event: "open-outline-plan", plan: {planId: string; planTitle: string}): void;
};
```

没有 slots 和 expose。

## 状态

- 没有打开的作品：来源下拉不可用，显示提示。
- 来源列表为空：提示把作品放进项目的 `reference/` 目录。
- 轮询：只在任务状态为“提取中”时运行；组件卸载时清理定时器和未完成的校验。

## 不支持

不在此处管理 `reference/` 里的文件，也不预览作品全文；需要查看原文请使用资源管理器。
