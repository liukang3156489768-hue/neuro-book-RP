# 覆盖新旧对比

选择“覆盖”重新提取大纲后，新提取的细纲和章节大纲不会直接替换旧内容，而是逐项列出新旧对照，由你勾选要替换的项并确认。没有勾选的项保持原样。

## 布局

顶部是汇总行（共几项、几项有变化）、“全选有变化的项”和“确认覆盖”按钮。其下每个条目一张卡：标题行含章名、类型徽章（细纲或章节大纲）和原文引用；卡内左右两栏（窄屏上下两栏）分别是“现有内容”和“新提取”，没有旧内容时旧栏显示“该章目前没有内容”。内容文字可换行，卡片本身不横向滚动。

## 交互

- 默认只勾选“有变化”的项；新旧相同的项不可勾选，标注“与现有内容相同”。
- 点“确认覆盖”上报当前勾选的项；一项都没勾选时按钮不可用。
- 提交后（`confirmed` 有值）组件变为只读，显示“已确认覆盖 N 项”，不能再次提交。

## 数据

```ts
type OverwriteItemKey = {chapterIndex: number; kind: "detail" | "outline"};
type Props = {
    items: OutlineComparisonItem[];
    /** 已提交的确认；null 表示还在等待确认 */
    confirmed: OverwriteItemKey[] | null;
    busy?: boolean;
};
type Emits = {
    (event: "confirm", items: OverwriteItemKey[]): void;
};
```

没有 slots 和 expose。组件不携带确认者信息，服务端按调用来源记录。

## 状态

- 等待确认：可勾选，可提交。
- 已确认：只读。
- `busy`：提交按钮转圈并禁用勾选。
- 没有任何条目：显示“没有需要覆盖的项”。

## 不支持

不支持逐字对比高亮，也不支持在对比中手工编辑新内容；需要修改请覆盖后到大纲工作台调整。
