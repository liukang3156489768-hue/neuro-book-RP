# 素材提取视图

“作品提取”里的素材提取一栏：从作品里提取角色、势力、物品、地点、特殊规则、文风、世界观、写作手法和素材特点，整理后写入 lorebook。流程分五段：选类别并开始；分块提取进度；实体归类（把同一实体的多个文件夹合并）；整合进度；审阅待写入清单并确认写入。它与大纲提取是两个互不阻塞的独立视图。

## 布局

未开始时先显示来源的分块预览，再显示类别多选和“开始提取素材”。块芯片显示块号、P 起止范围和字数，支持全选、清空、反选、点击切换及 Shift 连选；同时显示“已选 N 块，基础调用 N × 类别数 次；角色会在粗读后按出现情况追加逐角色提取”。任务开始后选择锁定，上方是进度面板，其下按阶段切换：等待归类时是归类面板；整合结束后是待写入清单；遇到同名冲突时清单被冲突对照取代；写入后清单上方出现写入结果。任务切换与删除位于宿主面板的模型选择右侧；删除会清理任务目录中的中间产物，已经写入 lorebook 的文件不受影响。结束后有“返回设置”。`390×844` 下纵向堆叠，不出现横向滚动。

## 交互

- 开始后分块提取在后台进行，页面轮询进度；全部分块完成时任务暂停，等你确认实体归类，确认或跳过后进入整合。
- 整合完成后任务显示完成（或部分失败），清单默认全选；调整后点“确认写入”。
- 确认写入前先检查同名冲突：有冲突时展示对照，逐个选择覆盖、另存为或跳过；无冲突直接写入。
- 写入失败的条目留在清单里，可修改后再次确认。
- 提取和整合阶段共用的进度面板支持单项操作，以及一键重试／跳过点击时的全部失败单元；它不处理最终写入报告中的失败项。
- “返回设置”只离开当前任务的结果视图，任务记录和清单保留在服务端，再次选择该来源会恢复。

## 数据

```ts
type Props = {
    /** 素材提取控制器，来自 useInspirationExtraction().material */
    material: MaterialController;
    /** 来源已就绪（分块预览已加载）；未就绪时不能开始 */
    sourceReady: boolean;
    /** 当前来源的完整分块；缺省选择全部，启动后不可修改 */
    chunks: readonly InspirationSourceChunkDto[];
    /** 提取使用的模型；缺省走服务端默认模型 */
    modelKey?: string;
};
```

没有 emits、slots 和 expose。与大纲视图一样，用户操作直接调用控制器的动作；素材写入的确认者由服务端固定为用户，界面不提交也不显示任何确认者身份。

## 状态

- 来源未就绪：显示空状态。
- 任务状态：提取中、等待确认（归类）、已完成、部分失败、已取消、已中断。
- 部分失败时仍可审阅已整合出的条目；失败的分块或整合单元可在进度面板重试或跳过。

## 不支持

不支持在不重新提取的情况下改动已选类别或块范围；清空块或类别时不能启动任务；也不提供写入后的回滚。
