# 改编参考素材选择

设计工作台改编模式的受控素材目录。通过 `query`、`category` 双向绑定搜索条件；目录、总数、下一页状态、已选来源和错误由宿主提供。组件只显示标题、类别与路径，不读取文件正文，不访问网络。

使用 nb-ui 的 FormInput、FormSelect、FormCheckbox、Button 和 IconButton。勾选或移除发出 `toggle(path)`，加载下一页发出 `load-more`。已选来源始终可移除，不受当前搜索或分类限制；最多 12 项，达到上限后禁用尚未选择的项。生成期间所有选择与搜索控件禁用。

目录滚动区域有高度上限；长路径换行，筛选栏和已选行在窄屏换行。空目录、读取中、失败及选择数量有可见状态；未选择时解释必须先选择参考素材。最终保存会新建设计素材，不覆盖来源文件。
