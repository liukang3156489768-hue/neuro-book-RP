# Inspiration 设计工作台

## 布局

这是设计模块的唯一宿主，使用全屏模态 `Dialog`。窗口顶部有“素材设计”“作品提取”两个页面切换：前者是下面描述的三栏设计工作台；后者是 `extraction/InspirationExtractionPanel`，用于对整部作品提取大纲与素材（见该组件的同名文档），首次切到时才挂载，之后用显示开关保留进度。宽屏分为聊天记录、对话输入、成果审阅三栏：记录和对话先让位，成果栏保留可编辑区域。窄屏将审阅区放到对话区下方；`390×844` 下聊天记录隐藏，输入、停止和保存按钮仍在各自滚动区内可访问。

工作台高度始终受窗口剩余空间约束。聊天记录、消息历史、输入区和右侧审阅区分别拥有滚动边界；连续追问产生长回复时，消息历史和审阅区在各自面板内滚动，不把输入区或保存按钮挤出窗口。输入区最多占聊天栏高度的 65%，参考选择较多时在输入区内滚动。消息和成果卡保留正文高度，不压缩成相互重叠的内容。窄屏上下两个面板分配窗口内的可用高度，分别滚动。

## 交互

父组件以 `modelValue` 控制窗口并接收 `update:modelValue`。用户可新建、打开和归档设计聊天记录；对话区显示用户指令和处理结果。输入区提供“原创 / 改编”切换；改编显示 `InspirationMaterialPicker`，搜索、按类别筛选并分页选择当前作品的最多 12 项参考素材。目录响应只有概览，没有正文。改编未选择来源时禁止发送并显示提示。

成果卡始终可编辑，只有点击“保存已审阅成果”才触发正式素材写入；改编保存新建素材并保留原来源。恢复改编草稿时还原创作方式和来源选择。切换创作方式或来源保留已有审阅草稿，但新请求只有方式与来源集合完全一致才携带旧草稿版本；只有这种情况下反馈可以沿用原始需求重做。追问和“重新设计”使用草稿自身来源快照，不受当前输入选择影响。消息与成果显示创作方式及来源名称。

所有请求与持久化由 `useInspirationWorkbench` 提供，组件本身不直接访问网络或共享状态。“作品提取”页的请求由其自身的宿主组件发出；提取结果卡上的“打开提取方案”通过 `open-outline-plan` 事件转发给页面，由页面决定如何打开大纲工作台。

生成、保存和单条重新设计互斥，参考选择在这些操作期间不可变。成果操作的运行状态使用模板顶层 Ref 绑定，空闲时“重新设计／追问”可用，不把嵌套 Ref 对象自身误判为运行中。

## 状态

没有聊天记录时显示欢迎面板和“新建对话”入口；生成中、无成果、错误和保存成功均有明确文本状态。原创成果明确标记为原创。运行中可以停止请求，保存中不可重复提交。

## 不支持

作品提取的分块选择、进度、归类和写入规则由 `extraction/` 视图合同定义。旧版“作品分析与提取”入口、旧提取消息和草稿不再保留；已保存到 `lorebook/` 的正式条目不受清理影响。
