# AgentCompactionStatus

展示一次真实上下文压缩的状态：正在整理重复资料或生成摘要时显示旋转指示、已完成批次与耗时；完成后显示压缩前后 token 和单独的摘要输入、输出、缓存及费用。摘要统计独立于主请求累计用量，不显示推算百分比。

## 数据

```ts
type Props = {
    state: AgentCompactionStateDto | null; // 受控，宿主已校验运行所属会话与 invocation
};
```

无 emits、slots 或 expose；attrs 透传根节点。状态为空时不显示。失败显示服务端原因，停止后保留终态。组件不拥有请求或取消行为，继续使用宿主现有停止入口。

## 布局与边界

内容使用主题语义色并自然换行，长错误在 390px 窄栏内换行，无固定宽度。运行时计时器仅刷新耗时，终态和卸载时停止；动画尊重减少动态效果偏好。批次与用量只呈现服务端真实数据，重连恢复由宿主完成。
