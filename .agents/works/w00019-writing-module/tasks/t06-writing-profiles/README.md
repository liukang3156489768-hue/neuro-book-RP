# 写作三角色 Profile 与主创工具

## 目标与范围

实现 [writing.collaboration](../../../../../docs/specs/writing/collaboration.md) 中三个角色的 Profile 与主创操作写作运行的工具，接入 t05 的写作工作流内核。

1. Profile：
   - 主创 `writing.lead`：与用户商定章节、任务类型与模式，发起、续写、停止写作，核对场景规划，讨论模式下把用户的决定转交运行，汇报进度与问题；
   - 助手 `writing.assistant`：读 `lorebook/` 与本章参考、指导文件（只读），提交场景规划、审阅结果与问题草稿；
   - 写手 `writing.writer`：只接收渲染后的提示，输出正文，不带工具。
2. 主创工具：查看写作状态、发起、续写、停止、应答场景规划、读本章正文。发起、续写与应答在后台任务中推进运行，运行停在等待应答、完成、停止或失败时把结果交回主创。
3. 助手工具：列出与读取可读范围内的资料文件；范围由运行所在章节决定，不取模型参数。
4. 每个项目一个写作运行入口，接真实会话与模型调用端口。

## 非目标

- HTTP 写作运行接口与进度界面：切片 7。
- 改写流程：切片 6。
- 真实模型调用验收。

## 验证

- Profile 合同测试：工具集合（主创不含资料读取与写文件工具；助手不含伏笔、线路与写文件工具；写手无工具）、初始值与输入输出 schema、提示渲染。
- 工具测试：
  - 主创工具在后台任务中推进运行并交回结果，停止、应答规划与重复发起的错误；
  - 助手工具拒绝范围外路径，章节取自会话初始值。
- `server/writing` 测试与应用 `typecheck` 通过；完成后更新 Spec 实现合同。
