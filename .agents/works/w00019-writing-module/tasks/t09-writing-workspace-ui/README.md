# 写作界面

## 目标与范围

切片 7 的界面部分，实现 [writing.workspace-ui](../../../../../docs/specs/writing/workspace-ui.md)，数据面用 t08 的写作 HTTP 接口。

1. 左栏“大纲”容器与大纲视图：写作方案切换、文风设置、按大纲库层级的章节树、状态与问题徽标、未关联正文的关联与解除关联、失败重试、文件变化自动刷新并保持展开与选中。
2. 中间：点大纲条目只读显示条目正文与段落标注，可跳到大纲工作台；点正文用项目富文本编辑器打开；无正文时显示空状态与“开始写作”；本章运行中正文编辑器只读并提示“写作进行中”，结束后载入最新内容。
3. 右栏“写作”容器与写作会话视图：一章一个主创会话，复用现有会话组件；灰显章节禁用输入并显示原因；顶部显示章节标题与状态。
4. 进度卡片：场景状态、展开查看提示与审阅、停止与继续、讨论模式的确认开始与退回修改、改写对照与替换或放弃；连接中断提示；刷新后按运行记录恢复。
5. 编辑器“改写选中内容”：把选区交给本章会话的输入框，由用户补充修改要求。

## 非目标

- 浏览器验收、390px 与主题检查、示例项目 Smoke、真实模型验收：切片 8。
- 界面偏好（展开、选中）持久化：本 Task 只在内存中保持。
