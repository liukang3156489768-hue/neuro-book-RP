# 写作运行的 HTTP 接口与进度投影

## 目标与范围

切片 7 的服务端部分，为 [writing.workspace-ui](../../../../../docs/specs/writing/workspace-ui.md) 提供数据面，行为合同见 [writing.collaboration](../../../../../docs/specs/writing/collaboration.md)。

1. 进度投影：从运行记录派生进度卡片所需内容。
   - 整章写作：场景列表与各场景状态（待写、写作中、审阅中、重写第 N 次、已通过、未通过），每次尝试渲染后的写手提示、写手产出与审阅结果。
   - 改写：目标段落、原文与新段落。
   - 两者都包括待应答项（主创核对、用户确认、确认替换）和运行结果。
2. HTTP 运行接口：按章列出运行、读取单个运行的进度、停止、续写、应答。
   - 发起写作和改写仍只经主创，不开放 HTTP 入口。
3. 章节会话：一章一个主创会话，按章节查找，首次发送时创建。
4. 用户在界面上停止、续写或应答后，运行停下时的报告交回这一章的主创会话，与主创工具发起的运行一致。

## 非目标

- 界面：t09。
- 浏览器验收与真实模型验收：切片 8。

## 验证

- 进度投影单测，用 Mock 运行生成的真实运行记录：场景状态、重写次数、提示与审阅、未通过场景、讨论模式确认、改写对照。
- 路由测试：参数校验、错误码映射、未开放发起入口。
- 章节会话查找与创建测试；`server/writing` 与写作工具测试、应用 `typecheck` 通过。
