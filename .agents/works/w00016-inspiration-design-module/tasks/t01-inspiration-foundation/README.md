# 设计模块接入与首个可用流程

## 目标

将 Inspiration 设计能力接入左侧模块栏，并以可拖动的非模态窗口呈现。原创成果经用户审阅确认后才进入当前项目对应的 lorebook 分类。

## 当前步骤

1. 只读核查现有导航、DialogWindow、模型调用、项目文件写入与内容引用合同。
2. 等待 Work 记录中的本地开发流程例外与本次交付范围答复；依赖步骤在答复前不执行。
3. 将已批准范围沉淀为 Proposal / Spec；创建隔离 worktree，保留主工作区已有变更。
4. 实现前后端完整闭环，覆盖项目切换隔离、取消、模型失败、审阅确认与路径校验。
5. 运行聚焦行为测试、受影响类型检查、文档检查；在 walkthrough 中记录精确命令、结果和未运行项。

## 开发者参与

本地开发流程例外与首版范围正在询问。真实模型调用、远端动作、数据库迁移、浏览器人工验收与数据删除仍需分别授权。

## 交付

实现、组件文档、行为规范、测试及可恢复记录。明确区分已实现能力、后续提取整合能力、实际验证与未验证项。
