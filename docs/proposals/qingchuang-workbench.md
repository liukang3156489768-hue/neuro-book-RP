# 晴窗工作台

状态：accepted

## 问题与目标

现有工作台密集贴边、设置面板在大屏过小；窄屏工作台的固定最小宽度挤占内容。2026-09-20 开发者选定晴窗 Demo，并明确要求先核实 UI/API，再实装；Demo 仅作为风格和布局参考。

目标是清透浅色、文学气息、悬浮面板、可收起抽屉和约占工作区三分之二面积的设置弹窗。保留真实业务、配置层次和所有既有工具入口。非目标是用 Demo 模拟数据替换产品、重写 Agent 或编辑器、改变权限、Provider、数据库和文件协议。

## 当前证据与决定

- `app/pages/index.vue` 组装 Project ready 门禁、工作区、行内 AI、Agent 和设置。
- `app/stores/novel-ide.ts` 拥有文件缓冲和冲突保存；重排页面必须保留该路径。
- `useConfigApi` 区分全局与项目配置，设置另有启动和浏览器作用域，不能合并成 Demo 的四个示例选项。
- `AgentChatSurface` 挂载生命周期拥有会话/SSE，动画不能偷偷延长或提前业务激活。

采用现有组件的外观与容器调整；现有 `light` 主题标记为晴窗，其他内置/自定义主题继续可选。独立整页重建方案会丢失业务入口；仅换色无法解决空间和响应式问题，因此不采用。

## 影响与回滚

不改变公开 API、持久化格式、配置 owner 或迁移合同。不改已有主题选择、不读取或输出密钥。颜色仍由主题系统拥有。部署、提交与远端操作另行授权；本地修改可逐文件撤回。
