# 大纲规划原创与改编流程重构

## 已确定行为

大纲规划工作台提供原创和改编两种创作方式。方式在新建会话时确定，首条用户消息产生后锁定；历史会话恢复自己的方式，只有新建会话才能重新选择。两种方式分别进入独立的规划提示词分支。

原创流程先只检查 `lorebook/` 各素材类别是否存在文件，再依据用户提出的情节按需读取角色、物品、势力、世界观、地点和笔记。缺少必要类别时提示用户先去设计工作台补充，不把全部正文加载到上下文。

改编流程先确认存在带 `source-extraction` 依据的原作提取方案；多个方案交由用户选择。随后检查角色、特殊物品、世界观、地点等类别是否存在。用户提供改编想法后，系统按原作章节、已有改编大纲和必要素材逐步确认，支持基于某一章节改写，也支持在两个章节之间插入原创章节。改编起点一次创建“改编方案+序号+作品名称”（或用户指定名称）、总纲、第一卷和第一章，并记录稳定来源锚点。

基础角色、物品、地点资料和提取记录只读；新的经历、关系、物品和地点变化随当前方案规划写入对应的改编记录目录。

## 实现入口

- 会话锁定：`useOutlineWorkbenchAgent` 与 `outline-workbench-session`。
- 提示词分支：`outline.planner` 及三个规划专家 Profile。
- 类别检查：`inspect_planning_material_requirements`。
- 改编工作区：`prepare_adaptation_workspace`、`prepareAdaptationWorkspace`。

真实模型的素材选择、冲突判断和多轮语义质量仍需单独验收。
