# 设计工作台素材改编

状态：accepted。2026-10-03 开发者要求为设计工作台的原创设计部分增加改编模式，并确认“另存为新素材，保留原素材”。行为合同见 [inspiration.design-adaptation](../specs/inspiration/design-adaptation.md)。

## 问题

现有工作台可以按八类专业方向生成原创草稿，但不会读取用户指定的现有人设、物品、势力等设定。直接把素材全部加入上下文会增加噪声；只在提示词里写对象名字也不能保证模型实际阅读。

## 目标与非目标

在素材设计页选择原创或改编，明确选择当前项目的参考资料，按用户要求重新设计素材。支持跨类别参考，例如结合角色、物品与势力资料设计一个新角色。沿用草稿审阅、编辑和确认保存流程。

本轮不覆盖原素材，不维护剧情计划，不读取其他小说项目，不加入共享库或向量检索，不调整作品提取流水线。

## 当前行为与证据

[设计服务](../../packages/neuro-book/server/inspiration/service.ts)负责 Inspiration 分派和八类专家调用；[保存边界](../../packages/neuro-book/server/inspiration/storage.ts)由草稿成果身份生成独立路径，并拒绝不同内容覆盖。[工作台](../../packages/neuro-book/app/components/novel-ide/inspiration/InspirationWorkbenchDialog.vue)已有审阅、反馈和对话恢复。

## 方案、备选方案和取舍

程序只读取用户选定的 lorebook Markdown，向协调者及专业设计师传递有来源路径与哈希的正文快照。列表只发现对象与路径，不加载全部正文。资料正文是参考数据，不拥有指令权限。

保留项和变化项由用户要求决定；没有说明的部分参考原设定保持一致，明显冲突指出而不凭空扩展为剧情。角色经历及关系若由用户指定，用于理解性格和动机，不自动照搬原作命运。

结果另存为新素材。未采用直接替换原条目的方案，因为它需要独立的覆盖确认、版本和冲突合同。本轮也不赋予设计 Agent 通用文件工具：读取由程序执行，正式保存仍由用户确认。

## 数据、接口、安全、迁移、发布与回滚影响

草稿增加可选创作方式与所选资料快照，旧草稿默认原创。重做、追问及恢复沿用该快照，保存元数据记录来源路径与哈希，不复制原资料正文到新素材的元数据。选择另一批资料或切换创作方式后作为新的设计任务。

目录发现及读取走当前 ready Project；拒绝越界、链接、缺失、空白、重复及超限资料，不静默截断。取消或切换项目后不接收迟到成果。没有数据库迁移、真实模型调用或远端发布。

## 对 Spec 的预期改动

新增 `inspiration.design-adaptation`，覆盖创作方式、指定资料、草稿来源快照、专家上下文、确认另存与失败恢复。原工作台规范链接该扩展，不改变作品提取合同。
