# 写手酒馆预设兼容

## 目标与非目标

仅场景和改写写手使用原生酒馆预设，在相同输入、初值、引擎与转换配置下得到一致的最终模型消息。已接入编辑入口、参数采用、作品绑定及输出管线；整体保持 planned，等待开发者统一验收。兼容范围以本文明确列出的引擎、接口和扩展能力为限。

不承诺任意插件、完整 SPreset 工作区、原生 Claude/Gemini 转换或随机输出逐字相同。开发者已明确仅兼容预设提示词，不要求同步兼容插件。预设正文和脚本是测试数据。

## 术语与参与者

资料助手是已审核输入的来源；user/char 是显式宏身份，与小说人物和 API 角色分离。槽位承载角色、Persona、场景、已选世界书、示例和历史；提供世界书文本不表示实现原生激活。当次编译记录冻结写手尝试的版本、消息与变量终态。

## 输入与前置条件

原生 JSON 保留 prompts、prompt_order、identifier、marker、扩展及未知字段。使用全局 100001 顺序；重复或缺失 identifier 拒绝。每个启用 marker 显式绑定，空值使用空数组；必需小说资料必须通过启用槽位或实际读取的写作映射进入最终提示词。

支持固定版本 legacy/native 两种原生引擎与文本 OpenAI Chat Completions；默认 legacy，可在专用编辑器选择。legacy 保留类别 pass 和非递归求值；native 支持原生嵌套条件、惰性分支、变量简写、索引、存在判断与删除。请求后处理支持原生空值、none、merge、semi、strict、single 及对应 tools 选项，claude 保留原转换别名；未指定时采用原生文件设置。tools 选项仅处理文本消息，不引入工具调用。strict 使用酒馆默认占位语句。

宏环境位于 bindings.nativeContext，人物、输入、模型、日期、时区、locale、随机种子和可表达的聊天元数据可显式绑定。编译捕获同一次时钟与随机种子并冻结；无时区日期按冻结时区解释，不使用服务端时区。日期和 duration 共用冻结 locale。未绑定的浏览器显示消息 ID、world-info outlet 等宿主能力明确失败。历史为文本 API 消息，未提供 swipe/send_date 等完整酒馆聊天数据时不宣称相应聊天环境等价。

正常与继续生成分别选择，支持多段历史及 continue_prefill。深度注入使用原生 depth/order/role，generation trigger 按当前生成类型筛选。继续生成需要启用历史且存在历史消息。

本地 JSON 导入仅在两个写手用途提供。默认 user=作者、char=写手，可显式修改；身份不从资料助手或小说人物自动推断。新导入默认映射将角色送入启用人物槽位、背景和补充资料送入世界书文本槽位、场景送入场景槽位，历史正文作为 assistant、任务作为 user。目标不存在时优先选择其他可读取资料槽位，或预设实际读取的固定名自定义变量；没有目标时保留未映射草稿，由保存校验说明缺失。所有必需变量必须保留，助手审核合同不变。

## 写作条目映射

新导入原生文件保存独立的 writerMappings，按写手原生条目 ID 配置资料槽位、local 或 global 变量。排除职责与输出要求，剩余按文风与样文、章节与上下文、人物与创作资料、场景与写作要求分组。每条显示原模板并提供映射下拉；多个条目可映射到同一目标，按原模板顺序合并，原生 JSON 不因映射修改。示例对话需通过绑定 JSON 提供成对消息，不能接收单条写作资料。

每个写作条目还可选择“直接排序”：writerMappings 的 prompt 目标引用该条目在 sourceJson 中的唯一普通条目，默认追加到全局顺序，角色和正文来自原模板。用户可以编辑正文、角色、启停、触发条件和深度并与酒馆条目混合排序；同一条目只走直接或映射中的一条路径。直接条目在业务渲染阶段填入写作变量，保留资料字面文本，不执行资料中的酒馆宏，也不参与预设变量初始化。原模板必需变量必须保留在编辑后的正文中，停用、未触发、移出序列或深度裁剪导致必需内容缺失均拒绝保存或发送。多个写作条目不能引用同一个直接条目。

切回“变量映射”移除此直接条目和所有角色顺序引用，恢复直接目标的 previousMapping 记录（没有记录时采用默认目标），失效目标不自动回退；直接模板和设置保存为可选 writerDirectDrafts 休眠草稿，不参与任何编译。重新切到直接排序以新标识恢复该草稿，默认追加到全局顺序；首次直接排序采用原写作模板。删除直接条目连同休眠草稿清除，该小节回到未映射，必需资料校验继续生效。旧配置未增加新字段时行为和快照哈希不变，完整配置和快照保存使用方式及休眠模板；原生 JSON 导出只包括实际源条目中的业务模板，回到酒馆时写作变量需要由相应宿主提供，不冒充酒馆可自动读取 NeuroBook 作品资料。

下拉静态扫描预设中定义或使用的资料宏及固定名自定义变量，包括 get/set/add/inc/dec/has/delete、key/index 形式和 native 的 .name/$name 简写；局部与全局同名独立。停用、未触发和仅初始化未读取的字段仍显示但不可选。动态变量名只显示无法确定的提示，不执行预设或插件来发现字段。源编辑使目标消失时保留配置并显示缺失；保存和预览拒绝无效目标，不自动回退。

开启映射的编译顺序为：加载作用域初值，执行本次启用提示词中的变量初始化，注入本次写作资料，最后展开消息。初始化阶段不包含本次映射资料；变量写入只在此阶段执行一次，展开阶段读取初始化和映射后的终态，不再重复 set/add/inc/dec/delete 的副作用。资料占位符同样在展开前填入。此为写作资料接入的显式阶段；没有 writerMappings 的旧配置维持原生求值顺序和既有绑定，不隐式迁移或改变旧快照哈希。回复正则仍从冻结变量终态正常执行自身副作用，不再次初始化或映射。

保存、预览和真实写作共用该流程。每个必需条目的完整渲染内容必须存在于编排消息中，否则拒绝发送，覆盖未映射、惰性分支未读取、初始化覆盖、正则删除和预算裁剪等情况；失败只说明条目和变量名，不记录作品正文。可选文风禁用和样文可不映射。只使用自定义变量、没有资料 marker 的预设也可导入和运行。旧预设可显式启用映射，转换已知模板小节并保留其余手工绑定；完整配置导出包含映射，原生 JSON 导出不包含 NeuroBook 映射。

## 输出与可观察行为

启用顺序、求值顺序和位置遵循对应酒馆行为。停用条目不求值；仅初始化变量的空条目虽不输出消息，其副作用保留。短 setvar 按上游保留，不自行修正。

保留三角色、边界与示例 name；strict 合并相邻同角色，转换中途 system 为 user，再合并并按需补首条 user。names_behavior 的 NONE/DEFAULT 不给普通历史增加 name；CONTENT 给非 system 历史加名称前缀；COMPLETION 使用原生 ASCII 清洗及 64 字符上限设置 name，未提供名称时采用对应 user/char 身份。system 历史视为 narrator；群聊与 sendas 元数据不在当前绑定范围。其最终结果作为请求及审阅依据，不追加旧写手模板或调用通知。

报告区分提示支持、扩展依赖和未验证环境。采样参数默认采用原文件，显式生成参数覆盖优先于原文件，两者均优先于 Profile/Provider 默认；单次调用显式 temperature 覆盖最高。原文件选择不切换服务商或模型。CUSTOM 接口按固定上游模型规则将 max/min 推理等级转换，其他实际支持参数在最终 payload 注入，保留零值。输出额度超过模型已配置上限、输入与输出超过模型窗口时明确失败，不静默截断。

上下文预算默认关闭；显式选择 claude、cl100k_base 或 o200k_base 词表及包含输出的总额度后启用。输出预留采用生成覆盖优先于原生输出额度，缺失或不小于总额度时拒绝。按固定版本 CUSTOM token 规则先为普通条目、资料、聊天边界和 continuation 预留，再从最新历史向前装载，含深度注入；第一条无法容纳的候选仍执行宏，更老候选不执行。示例整组装载，“优先保留示例”只改变分配顺序，不保证示例一定能容纳。裁剪导致必需作品资料完全缺失时拒发；其他本次启用槽位或保留历史有同一变量副本时允许。

预算报告 usedTokens 是后处理前的编排占用，含三 token 初始预留、不含输出；后处理可能增加文本，不将报告冒充最终 payload token 总数。Harness 使用同一词表重新计算后处理后的最终提示前缀，结合后续请求估算及输出额度检查实际配置模型窗口；显式预算不能超过该窗口。不开启预算时继续完整编排并使用既有估算校验模型窗口。tokenizer 必须与酒馆对照设置匹配，不能根据模型名称假定服务商实际分词实现。

回复按 raw → stored 正则 → display 正则处理，三份均持久化。只有 stored 结果可作为正文来源；普通正则仅 stored 生效，promptOnly/markdownOnly 按各自阶段生效。默认输出模式由启用预设是否要求 content 标签决定，并可修改为全文或指定标签。标签缺失、不完整、多段或为空时保留原始记录并返回空正文，沿用现有重写机制；分析说明不进入标签提取后的正文。display 记录不会替代历史正文，也不执行 HTML 内脚本。

正则查找宏替换支持 NONE/RAW/ESCAPED；ESCAPED 只转义每个宏的结果，保留表达式字面语法。替换、trimStrings 与查找宏使用选定引擎及同次变量状态；输出变量删除和新增/修改一样参与并发差量校验。动态查找表达式在执行阶段校验，非法表达式明确失败。

样本 Turing 正文质检 v3.11 按源码 SHA256 适配本地 30 条普通规则、2 条频率规则和结尾检查，报告交给助手审阅，不自动修改或否决正文。未知脚本仅登记，不执行；该脚本云端复核、交互补丁和聊天统计没有从浏览器恢复。扩展报告始终 fullEnvironmentEquivalent=false。

## 状态与转换

| 状态 | 事件 | 结果 |
| --- | --- | --- |
| 普通预设 | 显式导入 | 校验后保存原文件和绑定，供新尝试选择 |
| 已选兼容预设 | 开始尝试 | 固定版本，请求前保存最终消息与变量终态 |
| 已保存记录 | 审阅或恢复 | 复用原记录，不重新求宏 |
| 无当次记录 | 酒馆写手审阅 | 拒绝，不重新渲染伪造实际输入 |
| 已有尝试 | 切换或删除预设 | 保留历史快照和消息 |

新尝试采用最新选择。默认 local 按项目、用途、预设和写作会话隔离；同一会话的场景、重试及改写可延续，归档后仍使用原稳定身份。global 按项目、用途、预设隔离，跨会话延续但不跨作品共享。isolated 选项将两类变量限制到单次尝试；无项目的直接调用也隔离。初值用于作用域首次创建，新作用域或新预设重新初始化，已有作用域不被编辑初值覆盖。每个写手会话只承载一个请求身份，不同请求必须新建尝试。

编译收据与变量终态提交由同一 State Root 串行队列处理。完整编译收据单独保存，变量文件只保留 SHA256 索引；原子状态文件引用收据才算提交。session 投影写入失败时复用已提交收据，不重求宏。回复先冻结再提交变量差量，冲突明确失败并保留回复；恢复按原请求、编译依据和分支复用同一输出。保存记录不保证网络恰好发送一次。

## 副作用与数据

提示词管理持有全局预设与版本；写手会话日志持有编译结果。导入不修改第三方文件，不执行插件源码，不扩大权限。对照命令只读输入，只输出元数据、差异和未验证项，不输出正文或认证信息。

console 日志只解析字面值与字符串拼接，不执行文档。清洗日志即使消息边界完整，也不是完整原始正文证据。

## 失败与恢复

本次生效内容中的未知宏、EJS、未支持转换和缺失槽位明确失败；未触发条目不阻止本次生成。SPresetSettings 和条件脚本、未知插件字段保留并登记依赖，不执行；SPresetSettings 不进入模型消息，普通条目仍按原生 enabled/trigger 生效，不模拟插件条件。原生文件不能经普通平面 save/toggle 覆盖；专用编辑器修改名称、角色、顺序、启用状态、绑定或原生 JSON 后按同 ID 显式保存新修订。JSON 未知字段保留；内置保护、全局 revision 冲突和旧快照保护沿用现有合同。导出可选原生 JSON 或包含绑定/覆盖的完整配置；预览不调用模型、不推进持久化变量。

模型失败不撤销已保存编译记录。恢复读取已有记录；缺失或损坏版本不能回退当前预设。

## 边界与兼容

不改变其他 Agent、普通预设、历史正文、资料审核和正文写入保护。固定上游版本为 `06bde939fb1e9c4c8d8641d810f0a916b5bce127`。

原函数对照校验源码 SHA256，显式预算样例使用真实词表计数；未提供预算的编排对照仍采用零计数，不据此证明裁剪。两种引擎分别对照原生求值器，native 原模块由独立 Node VM 加载；宿主输入使用显式绑定。历史正则另行对照，不称完整浏览器运行。显示结果是可审查输出记录，不是酒馆 DOM 或通用插件宿主。原生 Claude/Gemini、多媒体、工具和世界书自动激活不属于本轮兼容范围。

## 验收与 Smoke

1. 相同预设、槽位和初值的消息与变量终态等于固定上游。
2. strict 与受支持继续生成的转换和末尾续写消息等于上游。
3. 真实 SDK 向本地捕获端发出的 messages 等于冻结结果，不重复注入；此场景不调用真实模型。
4. 改变审阅输入仍读取原记录；缺少记录明确失败。
5. 清洗日志报告边界、角色、文本匹配与参数观察值，不将缺失正文算作逐字通过。
6. 专用编辑保存修订、原文件未知字段、必需资料与历史快照保持，过时草稿返回 409。
7. 同作用域变量延续、不同作用域隔离、收据损坏拒绝、并发输出差量与失败恢复通过。
8. 实际 SDK 请求采用预设参数和显式覆盖；写作端口保留原文、提取正文、提交质检报告并恢复同次输出。
9. legacy/native、原生文本后处理、三个词表预算与示例优先级分别对照；裁剪丢失必需资料拒发，重复副本保留时允许；native+merge+预算的 SDK 实际请求等于冻结结果。
10. 两种引擎均先初始化再映射，副作用不重复；同名局部全局隔离、多条聚合、纯变量预设、保存重开和预览/实际编译一致，缺失或未读取目标及必需资料裁剪拒绝；映射样本的 SDK 请求等于冻结消息。

入口：应用包 `smoke:tavern-preset --preset <JSON> --bindings <JSON> --upstream <固定源码目录> [--reference <console日志>]`。无 bindings 只检查依赖；错误或上游不一致退出 1，清洗日志差异为诊断。真实模型使用现有独立入口与本地 Provider 配置。
