# `writer.pro` 规划交接

## 目标与非目标

本能力向正文写作 Agent 提供线路规划中已确认固定的正式章节大纲及其允许读取的上下文。它不提供规划写入、伏笔状态修改、线路重排或正文回写能力。

## 术语与参与者

正式线路节点是已通过结构检查、重复检查和所需语义分析并被用户或授权 Agent 固定的节点。正式内容包括节点关联的正式章节大纲、正式细纲、素材索引、参考文件和有效伏笔上下文。大纲库中未进入线路的内容不是正式写作上下文。

## 输入与前置条件

`writer.pro` 通过只读查询请求当前项目和目标线路/章节。请求必须携带版本或固定节点集合。查询服务校验节点固定状态、条目正式状态、引用有效性以及红/黄失效和重复标记；任一关键条件不满足即拒绝或排除，不能降级读取草稿。

## 输出与可观察行为

返回可解释的只读规划上下文：节点顺序、章节大纲、细纲、素材索引、参考文件、本章伏笔标记处的文本及其来源。伏笔只交接标记处的文本和稳定 ID、版本等来源信息，不交接伏笔定义正文，因为其中的背后关联和回收计划会让正文提前泄露后续剧情；需要呈现的内容由细纲和写作指导落实。标记为“待补”的参考文件作为告警一并返回。每项内容带稳定 ID、版本和来源位置。结果不包含未固定节点、草稿、建议、重复节点、红色失效节点或黄色待重分析节点。

## 状态与转换

本能力不引入新的规划状态；它读取规划服务当前状态。节点固定后可读；节点被修改、删除、重复或分析过期后，读取资格立即撤销，直到重新关联/分析并再次固定。规划版本切换不会静默改变正在执行的正文任务，应返回版本信息供调用方处理。

## 副作用与数据

只读查询无规划写副作用，可记录访问审计和上下文版本。正文 Agent 无权写入规划文件、线路、伏笔或 `lorebook/`。缓存必须以项目、线路和版本隔离，失效时不能返回旧正式结果冒充当前结果。

## 失败与恢复

项目关闭、版本冲突、节点失效、规划文件损坏或权限不足时 fail-closed，返回可解释错误和需要用户处理的原因。恢复后重新查询；不自动修复规划或改写正文。

## 边界与兼容

`writer.pro` 是按《新小说编写计划》原始设计新建的正文写作 Agent，尚未开发；现有 `writer` Profile 不是 `writer.pro`，不接入本交接。本能力是规划模块到正文模块的单向只读边界，与现有 Plot/Writer Brief 互补而不替换 Plot。规划模块只交接稳定 ID、版本和已固定正式线路上下文；不复制 Plot 的 Story、Thread、Scene、Promise、Decision、World Engine 关联或 Writer Brief，不建立第二套 Scene 真相源。任何写入请求均由服务端拒绝。

## 验收与 Smoke

- Given 已固定的正式线路节点，When `writer.pro` 查询，Then 返回按线路图格号从左到右排序的正式章节上下文和来源。
- Given 草稿或未固定节点，When 查询，Then 不返回该内容并说明原因。
- Given 节点被删引用标红或被改引用标黄，Then 查询 fail-closed，直到重新处理并固定。
- Given `writer.pro` 发出写请求，Then 服务端拒绝且规划文件保持不变。

## 实现合同

已实现规划侧的只读查询：
- ready Project 的 `read-writer-context` 接口按 manifest revision 与线路 version/hash 校验；
- 只返回当前固定且有效的正式节点（按格号排序并附格号）、已审阅细纲，以及位于本线路节点上的有效伏笔标记来源；伏笔来源不含定义正文。伏笔有效性按同方案格号跨线路判定，因此在其他固定线路埋设、在本线路回收的标记也会作为有效回收交接；
- 素材索引和参考文件交接规范路径，可按正式条目的引用清单读取素材内容，并返回来源审计；待补参考文件不可读取；
- 交接节点与细纲附带参考文件清单和场景写作指导，待补参考文件以 `PENDING_REFERENCE` 告警返回，同一告警也随细纲分析报告返回但不写入正式报告、不阻止采用。

未实现：
- `writer.pro` 本身尚未开发。此前曾把现有 `writer` Profile、通用文件工具、章级写作评审 workflow 和写作 smoke 改造成本交接的消费者，2026-09-26 已全部回退；

本能力维持 `planned`。
