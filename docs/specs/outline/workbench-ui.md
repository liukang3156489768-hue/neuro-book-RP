# 大纲规划工作台 UI

## 目标与非目标

本能力提供大纲规划的全屏桌面工作台：左侧常驻 Agent，右侧在大纲库、伏笔库、线路规划间切换。本阶段不适配小屏、窄屏或移动端，不在 UI 内实现领域状态、权限或分析逻辑。

## 术语与参与者

工作台绑定一个项目。左栏为 Agent 区，右栏为规划视图区；分隔线可拖拽。三段式切换按钮的三个视图名称固定为大纲库、伏笔库、线路规划。布局偏好属于项目 UI 状态，不属于规划文件内容。

## 输入与前置条件

打开项目并进入模块后加载项目布局偏好；无偏好使用左栏约五分之一的默认值。拖拽时左栏宽度不得超过窗口中线，并受可用内容的最小可用尺寸约束。Agent 设置包括思考两段式按钮、模型列表、温度数值框及增减按钮、讨论/自动模式切换。

## 输出与可观察行为

左栏从顶部到底部连续显示上下文和流式 Agent 输出，底部显示输入和设置。右栏顶部居中显示三段式切换，主体显示对应工作区。线路规划视图是方案线路图的画布：横向按格号 0…n 分格并在顶部显示格号标尺，纵向分行，拖动节点吸附到“格×行”；从节点连接柄拖线新建连线，向左或同格的连线在前端直接拦截；双击空单元格新建空节点；勾选模式下逐个点选节点组成线路并实时提示链是否有效。节点显示条目标题、状态色（有效、黄、红、空）和所属线路色标。分隔线拖拽后立即调整布局并持久化项目偏好；重新进入项目、重新打开项目或重载 UI 后恢复上次状态。

### 大纲库与伏笔库的直接编辑

- 大纲库的总纲、卷纲、章节大纲、细纲和伏笔库的伏笔使用同一套编辑方式：选中即可编辑，没有查看态与编辑态，也没有“编辑”“保存”按钮。正文是富文本编辑器，支持 Markdown 快捷输入，存盘仍是 Markdown。
- 停止输入约 1 秒或焦点离开表单时自动保存，每次保存调用一次领域编辑操作并带上当前版本；状态行显示“有未保存的修改”“正在保存”“已保存”“暂未保存（原因）”“确认后保存”“保存失败”“已在别处修改”。
- 需要作者确认的修改不会自动写入，而是在表单上方提示：总纲修改需“确认修改总纲”（被多个方案共用的总纲遵循下一条的写时分叉）；已正式采用的条目或已确认的伏笔保存后回到草稿，需“保存并回到草稿”；同时用于多个方案的条目不能原地修改，只能填写新标题另存为当前方案专属条目。每条提示都可以撤销修改。
- 标注从正文的浮动菜单添加：细纲的写作指导与段落参考，章节大纲的伏笔埋设、强化、回收。光标落在标注内时，浮动菜单提供切换伏笔、切换动作、填写说明和移除。
- 版本冲突：自己保存后的回显不打断输入；对象在别处（Agent 或另一个窗口）被改时，本地无修改则直接载入新内容，有修改则提示冲突，只能丢弃本地修改载入最新内容，不做合并。
- 切换条目、伏笔或方案前先保存；保存不了时提示可留下或放弃修改后切换。新建条目和伏笔直接以草稿创建“新×××”，选中并全选标题。
- 采用、排序、移动、确认设计、删除和细纲分析在有未保存修改时不可用，先保存再操作。不在当前方案中的条目只读。
- 草稿细纲与其他层级一样在条目操作行提供“正式采用”：点击后先做偏差分析，没有偏离和冲突时直接采用；有偏离或冲突时停在分析面板，确认偏离并逐条说明冲突处理后才能采用。所属章节大纲未采用或细纲结构有阻断问题时按钮不可用，并在按钮下方说明原因。

## 状态与转换

| 事件 | 结果 | 约束 |
|---|---|---|
| 首次打开项目 | 使用默认比例 | 左栏约 1/5，不能超过 1/2 |
| 拖拽分隔线 | 更新临时布局 | 受最大/最小边界限制 |
| 拖拽结束 | 保存项目布局状态 | 写入失败提示但不破坏当前显示 |
| 切换三段视图 | 替换右侧内容 | Agent 会话和未提交编辑不应被静默丢弃 |
| UI 重载/项目重开 | 恢复已保存布局 | 偏好损坏回退默认值 |

## 副作用与数据

只持久化项目级布局偏好和必要的 Agent UI 设置；规划实体、审批和分析由领域服务负责。流式输出通过 Agent 事件合同消费。布局偏好版本化，未来字段变化可回退默认值。

## 失败与恢复

窗口尺寸不足、偏好损坏、持久化失败或流式连接断开时，UI 保持可操作并提示用户；不把窄屏适配作为本阶段补偿方案。右侧视图加载失败不应清除其他视图或规划文件。

## 边界与兼容

应复用现有可调整面板 composable、主题变量、通用 Dialog、通知和错误解析能力。组件不得直接写规划文件，也不得自行决定伏笔状态、节点有效性或写入资格。用户的手动编辑只能调用领域操作，删除须先预览影响再带确认提交；Agent 提出的写入仍须经审批。与既有工作台 UI 的布局状态命名必须避免冲突。

## 验收与 Smoke

- Given 全屏项目窗口，Then 左 Agent 默认约占五分之一，拖到中线后不能继续扩大。
- Given 拖拽并关闭重开项目，Then 左右比例恢复。
- Given 切换三段按钮，Then 右侧依次显示三个视图且左侧会话保持。
- Given Agent 流式输出，Then 上下文列表增量显示，不等待完整响应才渲染。
- Given 偏好损坏，Then 回退默认布局并保留规划数据。
- Given 选中本方案专属的草稿条目并修改正文，When 停止输入约 1 秒或焦点离开表单，Then 自动保存且状态显示“已保存”，无需点击编辑或保存按钮。
- Given 修改已正式采用的条目、已确认的伏笔或总纲，Then 确认前不写入；确认后保存并回到草稿。
- Given 修改同时用于两个方案的条目，Then 只能换标题另存为当前方案条目，原条目不变。
- Given 本地有未保存修改时对象在别处被改，Then 提示冲突且不覆盖任一方，作者可载入最新内容。

## 实现合同

已实现 Project 作用域的布局 Storage 定义与会话、全屏左右分栏工作台、三视图的手动编辑界面（大纲库与伏笔库为富文本直接编辑加自动保存，线路规划为画布，写入均经领域操作；线路规划为 vue-flow 画布，吸附网格、格号标尺、连线拦截和勾选建线路尚待浏览器验收）及规划 Agent 会话容器。布局只保存于 Project UI Storage，Agent pane 通过现有 Session/SSE/审批合同消费真实会话，不在组件内执行规划写入或派生状态。当前聚焦合同覆盖 Storage 缺失／损坏／冲突恢复、Project 切换、活动栏入口、Agent 流式与异常标记展示；完整浏览器尺寸、拖拽中线、窄屏边界、大纲库与伏笔库直接编辑的浏览器交互（含浅色与深色主题）和运行中 Profile fixture 仍未验收，因此本 Spec 维持 planned。
