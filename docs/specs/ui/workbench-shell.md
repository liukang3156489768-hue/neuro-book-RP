# 晴窗工作台外壳

## 目标与非目标

以现代浅色和清晰分区支持长期写作；用可收起的辅助抽屉和大设置弹窗组织现有能力。Demo 只提供风格参考，不定义业务数据、API、保存机制或 AI 流程。不重写正文、Plot、World、模型配置或权限。

## 术语与参与者

主工作台由活动导航、当前作品、工具抽屉、Markdown Studio、行内 AI 与 Agent Surface 组成。设置包括启动、全局、项目、浏览器作用域。浅色晴窗对应已有 `light` 主题 ID。

## 输入与前置条件

继续使用登录状态、Project open/presence ready 与 user-assets 门禁；未就绪不得展示旧 Project 可编辑数据面。现有主题与编辑器偏好继续生效。API 参数沿用 `workspaceKind`、`projectRoot` 和会话身份，不从新展示文字推导身份。

## 输出与可观察行为

- 桌面面板使用间距、圆角、清晰边界，正文排版偏好保持用户可控。
- 活动导航保留书架、文件、角色、剧情、World、Trace、变更、Agent、账户与设置等现有入口；收起左侧工具后当前作品仍可辨识。
- 工具和 Agent 支持收起/展开；窄屏抽屉覆盖辅助空间，不能把正文挤出屏幕，关闭按钮始终可达。
- 设置默认约 82vw × 82dvh（约三分之二面积），窄屏使用接近全屏的可滚动布局；保留四个作用域、全部条件分类及保存/恢复。
- 页面型功能窗口与设置共享同一比例：剧本、世界引擎、请求记录、变更收件箱、Profile 工作台、图片预览、会话及其树、Diff、模型管理和作品资料详情。任务、上下文检查和主题编辑等可拖动窗口首次按同一比例居中，之后保留拖动位置。简短确认和输入框继续按内容布局。
- 晴窗使用现有主题变量，已保存的其它主题选择不被视觉升级覆盖。

## 状态与转换

抽屉沿用主页面已有状态，隐藏的面板不能获取焦点或接收指针输入。Agent 的挂载与停止订阅语义不因动画改变。设置加载/保存中沿用禁止离开的规则；dirty 草稿离开语义维持当前实现。动画尊重 `prefers-reduced-motion`。

## 副作用与数据

布局不新增业务请求、持久状态或存储。主题选择经现有 `useThemeManager` 保存全局配置；文件写入由 store 保留 `baseContent`/`expectedMtimeMs` 冲突协议。配置保存依然通过原面板与 `useConfigApi`，不整包覆盖凭据或跨作用域写入。

## 失败与恢复

保留文件冲突弹窗、API 错误通知、Project 重连和 Agent SSE 恢复路径。主题保存失败仍回滚。布局不得将失败显示为已保存、虚构字数/生成结果或吞掉模型配置错误。

## 边界与兼容

不改变后端 API、数据库、产品资产或桌面桥合同。书架、user-assets、IDE/Agent 两种模式与暗色/自定义主题继续工作。只扩展本次已批准的表现与响应式行为；其他缺口单独记录。

## 验收与 Smoke

- 1440×1000：打开真实工作台，文件、Agent、设置可操作，悬浮面板间距明确。
- 390×844：无页面级横向滚动；抽屉关闭与设置分类、保存/恢复操作可达。
- 文件面板关闭后编辑区扩展，隐藏控件不进入键盘路径；user-assets 也可以收起。
- 设置切换四个作用域保留既有分类与禁用条件，不发送模型测试请求。
- 原文件和会话 API 边界通过聚焦逻辑测试验证；真实模型另行授权，未调用不得声称通过。
- 主题切换只影响外观；已有主题、字体、项目和会话不被替换为 Demo 内容。

## 证据

批准依据：[晴窗提案](../../proposals/qingchuang-workbench.md)。调查与实际验证：[UI/API 连接记录](../../testing/qingchuang-ui-integration.md)。本轮已实装并完成主要桌面/窄屏验收；窄屏辅助面板互斥的最终浏览器复验及 user-assets 收起验收受审批故障影响未闭合，本合同暂保持 planned。
